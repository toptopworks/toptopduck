# 会话起步模型姿势:per-adapter 上次选择回填

## Decision

1. **新会话起步的模型/思考强度 = 该适配器的上次选择**（已选、注入）。`app-config` 新增 per-adapter 记录 `last_model_postures`（适配器 id → `{model, thought_level}`，serde default 空表）；回填后为已选态（turn 注入该模型/强度），「默认（推荐）」仅在**从未选择或已清除**时出现。resume 恢复会话自身姿势、不回填；目录不含持有值时按既有诚实渲染合成行兜底。
2. **per-adapter 作用域**。模型 id 是适配器命名空间的，不同 CLI 的目录互不相通——记录与回填均按适配器 id 独立进行，跨适配器不迁移。
3. **写入与清除**。每次成功的模型/强度 set 更新该适配器条目；「默认（推荐）」清除行置空该条目——下次起步回到「默认（推荐）」，回填不会让清除失效。
4. **悬空与漂移保留**。条目指向的适配器未检测到、或其目录已不含该模型时**保留不清**（重探测/目录刷新后自动复效）；目录不含的持有值按既有诚实渲染合成行显示；normalize 仅清形状非法条目。

## Context

模型/思考强度是 per-session 姿势（ADR-0095）：起步未选择（不注入、CLI 按自身默认执行），会话内可改选、下一轮生效。ADR-0099 把姿势抬升为 bar 常驻文字按钮后，冷启动 bar 可预选姿势（选择进 pending，首次提交随会话创建写入）。跨启动的「上次用过的模型」此前不为人知——每次冷启动都回到未选择态，高频微调姿势的用户每次重复同一选择。

## Why

1. **起步姿势与默认运行时同构**：`default_runtime` 记「用哪个运行时起步」，本决策记「用哪个模型姿势起步」——机器级起步偏好一层管齐，冷启动 bar 免于重复设置。
2. **显示即生效**：回填为已选（注入），不存在「显示上次值但实际不注入」的分裂态；「默认（推荐）」严格锚定未选择。
3. **与默认运行时的分工**：ADR-0098 否决的是运行时维度的 last-used 起步（低频显式偏好，静默延续未表达意图）；模型姿势是高频微调（会话内随时改），为它设显式设置项与使用频率不成比例，且回填可经「默认（推荐）」清除行一键显式撤销——隐式延续可被显式否定。两者正交。
4. **保留悬空条目**：CLI 重装或目录变化后用户选择不被静默清除，重探测即复效。

## Considered options

- **仅显示回填建议、不注入**：显示与实际生效分裂，「默认（推荐）」失去未选择锚定，文字按钮显示态超出四态。**否决**——回填即已选注入。
- **全局单值作用域**：跨适配器回填大概率引用当前目录不存在的模型 id，合成行兜底从异常路径变常态。**否决**——per-adapter。
- **localStorage 存储**：影响 turn 注入的领域状态不归 webview 存储（既有 localStorage 先例仅宽度类视觉偏好），且随 webview 缓存清理丢失。**否决**——`app-config`，与 `default_runtime` 同层。
- **normalize 清悬空条目**：适配器未检测到或目录不含即清，CLI 重装/目录刷新后无法自动复效，静默丢用户选择。**否决**——保留，仅清形状非法。

## Consequences

- 校准 ADR-0098（其「默认（推荐）」为未选择态显示文案的陈述）：锚定由未选择态收窄为从未选择或已清除；四态显示矩阵不变，已选态来源扩展为本次选择或起步回填。
- 校准 ADR-0099 Decision 3：文字按钮已选态在冷启动即可出现（回填值）；级联菜单「默认（推荐）」清除行同时置空起步回填条目；冷启动 pending 模型姿势初值 = 回填值，显式选择覆盖（与 pending runtime 初值 = 默认运行时解析同构）。
- 会话内改选与冷启动预选共用单一写入点（成功的姿势 set 即更新条目，IPC 层）。
- `app-config` 新增 map 字段：serde default 空 map 前向兼容，既有配置文件无该 key 不迁移；format_version bump 与否实施期定。
- **被 ADR-0102 延伸**：Decision 1 的回填作用域从「新会话起步」扩为「新会话与会话内换运行时起步」；resume 不在其列（resume 恢复会话自身的姿势对）。见 ADR-0102。
