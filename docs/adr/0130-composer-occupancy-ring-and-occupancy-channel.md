# 上下文占用显示：composer 三态环与占用采集通道

## Decision

1. **占用显示立法：composer 三态环。** QuestionBar 工具栏行发送簇行首（运行时选择框前）常驻占用环，三态：全环（窗口已知：百分比弧，超 70% 警示色、超 90% 危险色）、空心环（只有分子：轨道无弧，读数为末次往返计数）、不渲染（无任何占用上报）。hover 弹层是与运行时选择器同组件同 token 的 Tooltip 单行 pill：全环「N% · N / N 上下文已使用」（百分比一位小数、向下取整、百封顶，超限由满弧加危险色表达）、空心环「已使用 N tokens · 上下文窗口未知」；会话合计与技术折叠不进弹层——账单语义的显示面唯一落在轮卡 footer（ADR-0129），Thread 标题行合计退役后合计无独立显示面。绝不以猜测的分母呈现百分比。

2. **分子按协议分轨取末次往返。** 协议分轨在每个逐往返通道的采集点一次做对：内置循环在 fold 的末次往返处 latch，claude stream-json 通道 latch 末个 assistant 帧的 usage（缺帧按 result 帧兜底，与账单同源同序），codex 事件流通道 latch 末个完成窗口的 usage——Anthropic 协议取末次往返 total-side input（普通输入 + 缓存读 + 缓存写——全量重发语义下末次往返的输入即上下文规模实测）；OpenAI 协议取末次往返 total（输入 + 输出——server-side chaining 下 total 即活跃上下文规模）。ACP 通道直接采用占用快照的 used。latch 为替换式——末次往返即最新上下文实测，取消的轮次保留其已报读数；无已报往返即无占用（fail-closed，绝不落零读数）。占用随轮次持久（审计面轮级可选字段，serde default，旧 recipe 零迁移），经前端轮次类型透传。

3. **占用通道与账单通道分界。** ACP 占用快照（used / size）进占用显示通道，不进 ADR-0129 的账单归集——该通道轮次账单仍恒 fail-closed，ADR-0129 账单侧裁决一字不动。快照无输入输出拆分、不构成计量证据的判断不变；但它是唯一协议自报的占用原语，占用 UI 立法后有了合法去向。

4. **分母唯一来源是显式配置。** ProviderProfile 增可选 context_limit（serde default 零迁移），缺省即空心环。CLI 通道探测面——claude-code 控制面 initialize 的 models[] 条目与 codex app-server v2 Model——均无窗口字段（逐字段核验），空心环是这些通道自身的终态，配置 context_limit 后经分母合并出全环，不设探测扩展。

5. **显示词汇与数字格式校准。** 计量词汇统一全称（输入 / 输出 / 缓存写入；思考数不变），轮卡 footer 与弹层同源词条；弹层收敛为单行 pill 后，主行不再携带「末次往返 / 窗口」插语——读数形态自明，窗口未知由空心态文案显式作答；compact 数字弃 Intl 记法（zh-CN 渲染「万」、de 系小数点与千分位歧义），换固定 K/M 缩放（一位小数、剥尾零），占用百分比与 K/M 同构（一位小数、向下取整、百封顶），格式化单咽喉不变——0129 的绝对数显示与单一格式化面裁决保持。

## Context

ADR-0129 落地轮次账单时裁决「上下文占用不设专门计数器与 UI」，前提是计量仪器未建、分母无来源、占用读数无显示去向。仪器现已建成（轮次 usage 四通道采集与轮次级持久），分母版图也已实证：CLI 两家探测面无窗口字段、协议唯一自报面是 ACP 占用快照、配置面自有。会话合计彼时落在 Thread 标题行小字，与其消费时机（发送决策）分离。本决策立法占用显示、给占用原语合法去向，并把会话合计迁到消费点。

## Why

1. **三态是证据形态的诚实映射。** 分子、分母、双全三种证据状态各有一个形态：缺什么显什么，绝不猜分母——百分比只对实测窗口成立，与 0129 的 fail-closed 立场同源。

2. **分子的协议分轨不可统一。** 两家协议的 total 语义相反：Anthropic 全量重发下 total 不等于占用（末次往返的输入才是），OpenAI 系 chaining 下 total 即活跃上下文。分轨在采集点一次做对，显示层零判断。

3. **占用与账单是两种事实。** 占用是参考读数（外部 agent 的上下文压缩使读数非单调），账单是计费证据；把无拆分快照混入账单归集，正是 0129 否决的「下界伪装成完整账单」的同型错误。

4. **composer 是占用与合计的消费点。** 两者的消费时机都在发送决策——下一轮带多大上下文、会话已消耗多少；常驻发送簇行首让读数在决策点可见，轮卡面保持账单语义不碎片化。

5. **词汇与格式单源收敛。** 全称消歧——计量显示面上单字缩写与「缓存写」放大歧义；固定 K/M 消除 Intl 记法的 locale 形状漂移。两处都是单点替换、全显示面受益。

## Considered options

- **CLI 通道分母接入（扩展探测 schema）**：两上游探测面均无窗口字段（claude-code models[] 八字段、codex v2 Model 十九字段，已核验），无数据可接。**否决**。
- **Anthropic models API 自动回填 context_limit**：仅一手端点有效，网关与兼容端点响应形状各异，为部分用户省一步配置而扩探测与解析面。**否决**，出现真实诉求另议。
- **click 触发弹层**：环是常驻参考读数，hover 与其低成本瞄读的消费模式匹配，且位置在发送簇行首、不拦截发送路径热区；click 的防误触收益在此不抵多一步交互。**否决**。
- **无分母时隐藏整环**：分子（末次往返计数）本身是有效读数，空心轨道诚实表达「窗口未知」而非信息为零。**否决**。
- **占用读数随轮卡 footer 表达**：占用是会话级参考，消费时机在发送决策；随轮次面呈现碎片化且与账单语义混淆。**否决**。
- **成本 / 价格随弹层展示**：0129 已否决价格换算，无新事实。**否决**。

## Consequences

- 真实 ACP agent 是否实发占用快照未实测：实发与否决定该通道为全环或空心环，两者均已立法，fail-closed 兜底。
- 旧会话轮次无占用字段：resume 后空心环，直到新轮次落占用——诚实降级，不回填。
- 配置 UX 存在已知债：普通用户难以得知窗口数值；更好分母（自动回填 / 模型目录 / 预设档）待真实诉求另议。
- 词汇与数字格式变更波及既有显示面测试断言（轮卡 footer、占用 pill）。
- Thread 标题行合计与弹层合计相继退役后，会话合计无独立显示面——账单证据唯一显示面是轮卡 footer。
- 三态成为占用显示的横切契约：新增采集通道的验收含「无分子不渲染、无分母空心、绝不猜分母」。
