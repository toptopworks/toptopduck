# composer 运行时选择:入口三分与浮层两级单选

## Decision

1. **运行时选择的三个入口各司其职**：(a) 图标触发器浮层是运行时切换的**唯一**入口；(b) 触发器前的常驻文字按钮是下一轮生效姿势（模型/思考强度）的**只读预览**，所选运行时有模型目录时可点击打开级联菜单选择模型与思考强度；(c) 配置动作（档案增删改、`profile.model` 手输、钥匙管理、CLI 管理与探测）全部归设置页，composer 不承担配置表单。触发器沿用统一入口图标（非 provider logo，ADR-0071）；具体 glyph 选型属实现。

2. **浮层为两级单选**。一级单选二项：「API 接入配置」/「本机 CLI」（与设置页运行时 section 两子 tab 同名，术语对齐）；二级随一级展开——选「API 接入配置」时为档案子单选列表（活跃档案 ✓，点选即切换 `active_profile`，全局生效语义不变；零档案显「未配置」）；选「本机 CLI」时为 detected CLI 子单选列表（仅可用项）。底部保留「管理外部运行时 →」链接。诚实表面保留：档案行的无钥匙标记、所选 CLI 未 detected 的顶部警示、未探测 CLI 的「去设置页测试」引导。

3. **文字按钮四态显示**（落定 ADR-0098 未决项「模型按钮四态」）：内置运行时显活跃档案的 `model` 字段（空显「—」）；零档案显「未配置」；CLI 无目录或未选择显「默认（推荐）」（未选择态文案，`model: None` 不注入）；已选择显「{model} · {strength}」（强度未选只显模型）。无目录的静态态渲染为**无箭头标签**（不伪装可点击按钮）；有目录时为按钮，点击打开级联菜单——一级行（模型 / 思考强度）行内显示当前值，二级为选项列表 ✓ 标当前项 + 顶部「默认（推荐）」清除行（copy-in dropdown-menu 的 Sub primitive）。既有诚实渲染机制不变：目录未包含的持有值合成行、选择失败行、persist 挂起行。

4. **默认运行时的写入口归设置页**（落定 ADR-0098 未决项「写入口形态」），composer 不加快捷写入口——composer 的选择入口（浮层 + 文字按钮）均为会话级姿势操作，机器级偏好（ADR-0098 默认运行时）的编辑与管理动作同一处（设置页运行时 section）。

## Context

双运行时（ADR-0081/0085）落地后，composer 边的运行时选择器演化为双段重面板：内置段（档案下拉 + model 手输 + key 状态块 + 「打开设置」按钮）与外部段（适配器行列表 + 模型/思考强度 select）。切换运行时与查看下一轮姿势这两个高频动作被埋进承载低频配置的重面板；「下一轮用谁」（运行时、模型、强度）仅 hover tooltip 一处可见。ADR-0098 固化零档案合法与默认运行时起步后，留下两个实施期未决项：模型按钮四态的显示规格、默认运行时写入口形态。

## Why

1. **高频动作与低频配置分家**：运行时切换与模型/强度选择是每次提问前的高频操作，入口应一步直达；档案与钥匙配置一次成型后极少变动，归设置页与运行时管理收敛方向（ADR-0091）一致，重面板职责减半。
2. **姿势常驻可见**：「下一轮将用什么」抬升为 bar 上的常驻文字按钮，摆脱 hover 发现；模型/强度比运行时名更贴近提交前的关注点（运行时名继续由 tooltip 承载）。
3. **术语诚实**：「默认（推荐）」严格绑定未选择态（CLI 按自身默认执行），内置零档案显「未配置」不冒充默认（ADR-0098）；静态态不渲染箭头按钮，无假操作。
4. **浮层术语与设置页对齐**：一级二项沿用设置页两子 tab 名称（「API 接入配置」/「本机 CLI」），两处心智同一套词汇。
5. **会话级与机器级分离**：composer 三入口全部操作会话级姿势；机器级偏好编辑不混入会话面板。

## Considered options

- **浮层保留配置组（model 手输 + key 状态块 + 打开设置按钮，或仅留档案下拉）**：低频配置占据高频路径，重面板职责不减。**否决**。
- **原生 `<select>` 承载浮层单选**：行级诚实标记（无钥匙 / 未 detected 警示 / 未探测引导）无处安放，静默丢失既有保证。**否决**——两级单选行列表。
- **文字按钮兼任运行时切换入口**：预览与切换职责耦合，运行时切换失去唯一稳定入口。**否决**——切换只在图标触发器浮层。
- **文字按钮显示运行时名**：运行时名已有 tooltip 承载，提交前更高频的确认对象是模型/强度姿势。**否决**。
- **级联菜单形态自研 disclosure**：focus trap / 键盘导航手写易漏，栈内已有 dropdown-menu Sub primitive。**否决**——copy-in primitive。

## Consequences

- **校准 ADR-0071**：其 Decision 中 popover 面板的配置职责退役——model 下拉（现状为手输框）、key 状态、「打开设置」入口移出浮层归设置页（key 诚实标记降为档案行级标记）；档案下拉保留但形态变为两级单选的二级；「hover tooltip 轻量预览」升级为常驻文字按钮（本 ADR 四态）；`model` 写回 `profile.model` 的机制不变（编辑入口移设置页）。
- **落定 ADR-0098 两个未决项**：模型按钮四态显示规格（本 ADR Decision 3）、默认运行时写入口形态（设置页控件，composer 无快捷写入口）。
- **四态文案的载体**从既有浮层内 select 变为 bar 文字按钮 + 级联菜单；模型/强度选择的 IPC、目录优先级链（ADR-0096 Decision 6）、诚实渲染（目录未包含持有值的合成行等）与失败面全部沿用，仅 UI 载体迁移。
- **冷启动与会话两态接线不变**：会话内经 `setSessionRuntime`/模型 set IPC，冷启动写 pending state（初值 = 默认运行时解析结果，ADR-0098）。
- 级联菜单与两级浮层基于 copy-in dropdown-menu / popover primitive；具体视觉与文案属实现。
