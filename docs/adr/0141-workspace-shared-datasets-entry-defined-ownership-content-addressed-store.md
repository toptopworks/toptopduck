# 工作区共享数据集：入口定归属与内容寻址快照存储

## Decision

1. **归属判据：入口即落点即可见性。** 会话面板 ingest（dropzone/composer，现行入口）落会话树快照目录、会话私有——现行代码零改动；工作区数据集面（新入口）落工作区 store、工作区共享——全新域；result_N 派生恒为会话私有；explore 对工作区文件的 in-place 读（ADR-0137 D3）照旧零拷贝。判据全部机械可判，agent 与用户均无归属决策点。

2. **共享机制：工作区 store 内容寻址、硬链接与文本清单。** 快照物化为 `<工作区>/.toptopduck/snapshots/<sha256>.duckdb`（源文件流式 SHA256 为键，命中即免转换）；会话侧经硬链接持有同一物理文件。物化纪律：临时名与原子 rename（单一物理文件不允许并行写者）。清单为文本文件，条目记 reference_name、指纹、列 schema、行数、样本、隐私、源路径。

3. **可见性：清单卡片自动注入与惰性 attach。** 绑定会话的 turn 注入面并入工作区数据集卡片；SQL 首次引用共享数据集名时现场硬链接进会话树并 ATTACH READ_ONLY，长驻至会话结束，无人引用则永不 attach（attach 上限 200 的面因此收窄）；attach 前校验清单指纹，失配则重挂新文件（replace 语义）。**卡片名恒等于挂名**为硬不变量——agent 的 SQL 直接引用卡片名，任何分叉都制造看得见查不到的死卡片。

4. **入口形态：侧栏工作区区段管理按钮，点击开模态管理面板。** 列表、浏览添加（picker）、删除、替换、隐私修改全部在模态内；侧栏本体不内嵌列表（空间与干扰）。

5. **可见性边界严格跟随工作区绑定。** 无绑定会话不可见共享面（卡片不注入、agent 不感知）；不提供运行中改绑——ADR-0137 绑定不可变不破，旧会话的共享需求由新开会话承接。

6. **命名冲突：私有让位，共享保名；仅既成占用时共享消歧。** 私有 ingest 的消歧占用集并入共享清单名；共享挂名被私有历史占用时，共享源挂消歧名且卡片随之（卡片名恒等于挂名）。共享名是跨会话稳定的工作区公共词汇表，漂移成本压在一次性、会话内的私有改名上——即现行消歧的既有语义。

7. **turn 内变更采 turn 边界生效，不拒绝、不加锁。** replace 与 delete 立即落清单；进行中的 turn 靠硬链接继续持有旧物理文件（快照冻结，正确性有保障），turn 结束后新引用经指纹校验拿新或标 stale。零新增同步机制——跨会话 in-flight 聚合锁不做。

8. **完整性姿态：诚实报错，不静默自愈。** 清单缺失视为空清单（新工作区）；清单解析失败保留 `.corrupt` 副本并在面板显式报错；条目在而 store 文件缺则该条目标「文件缺失」，引用它的 SQL 报工具错误（agent 可自纠）；无条目孤儿文件启动清扫（无引用即零风险删）。

9. **resume 持久化共享挂载三元组：挂名、清单条目名与指纹。** recipe 增共享挂载事件；resume 时指纹仍匹配则原挂名回，条目没了或指纹变了则该挂名标 stale。挂名稳定是 replay 重放链正确性的前提（materialize 的 SQL 记在 recipe，挂名漂移即断链），三元素缺一不可。

10. **隐私为工作区级资产属性。** DatasetPrivacy 在管理面板修改，对全部绑定会话即时生效（turn 注入时读清单最新值）；默认值沿用现行（send_samples 开），不另立保守默认。

11. **共享面第一刀格式：CSV、Parquet、JSON 与 JSONL，拒 xlsx。** 拒绝时报错提示转 CSV/Parquet 或走会话私有源（私有面 xlsx 支持照旧）。

12. **误用定性：私有大源被多会话重复拖入属于使用错误，系统不做物理兜底。** 正确形态是作为工作区共享数据集；无检测提示、无去重兜底、不留升级路径。

## Context

多会话读同一份大数据集时，现行几何的成本是线性的：ingest 是每会话一次的全量 copy-in（`ingest::loader::copy_in` 将源文件经 DuckDB reader 转成会话树内 `<alias>.duckdb`），N 个会话即 N 份磁盘拷贝与 N 次分钟级转换。快照与工作集落会话树（ADR-0136），工作区（ADR-0137/0138）只承担外部运行时 cwd 职责——两条轴不相交，「同一工作区的会话共享一份数据集」没有承载面。典型场景：一份大数据集作公共底座，各会话配私有小数据或 MCP 拉取的数据做综合分析（join 共享大表与私有小表）；成本恰好集中在「大」上，私有小表的每会话 copy-in 成本可忽略。

## Why

1. **入口即意图，零猜测**：用户拖给会话即私有、在管理面板中添加即共享，意图在入口选择里表达；由系统判落点（手动 ingest 默认进工作区）则产生无法机械裁决的分叉，且私有入口被私有小数据场景需要。
2. **生命周期外包给文件系统**：硬链接的链接计数即引用计数，会话删树只是 unlink，最后一个链接消失时物理文件自动回收——零 sidecar、零跨会话广播；DuckDB 在 Windows 以共享删除级打开快照文件，attach 持有中删除兄弟链接乃至被 attach 路径本身均不阻塞、不破坏进行中的会话（duckdb 1.x bundled，Windows）。
3. **快照世界观一致**：turn 边界生效与 ADR-0004 冻结快照同构——turn 看到的是它开始时的世界，外部清单变更不打断、不锁死。
4. **每会话独立引擎不破**：多实例并发 READ_ONLY attach 同一文件（duckdb 1.x bundled），ADR-0005 沙箱隔离与 admin/sandbox 分面原样保留，共享只发生在文件层。
5. **卡片名恒等于挂名**：agent 的 SQL 直接引用卡片名，挂名与卡片名任何分叉都制造「看得见查不到」的死卡片。
6. **拖放通道在生产 webview 不可达，picker 唯一入口**：Tauri v2 `dragDropEnabled` 默认开启时原生层接管窗口拖放，WebView2 内 DOM drop 事件不触发，面板收不到拖放；WebView2 的 File 对象无 `path` 属性（Electron 专属），hidden input 选不出绝对路径——拖放与文件输入两条通道均不可达，浏览添加（picker 返回绝对路径）是唯一可靠入口。

## Considered options

- **会话侧显式挂载（挂载集由用户装配）**：把工作集装配的认知成本转嫁用户，且引入会话中持续维持的状态（挂载几个、轮间如何调整）。**否决**。
- **手动 ingest 默认进工作区（私有源默认值消失）**：落点分叉无法机械裁决；私有入口被私有小数据场景证伪；配套迁移面（生命周期事件归属、隐私重构、读旧写新）不匹配收益。**否决**。
- **app 级全局 store（跨工作区去重）**：牺牲工作区隔离语义换跨工作区去重，公共数据集跨工作区重复的场景价值低。**否决**。
- **result_N 视图化（工作区文件视图免 copy-in）**：纯投影、巨大、多会话共用三者同时成立的窄场景，explore in-place 已覆盖探查需求。**否决**——记录已知成本，现象出现再议。
- **跨会话 in-flight 聚合锁（turn 中拒绝清单变更）**：需要新的跨会话 turn 状态聚合与广播，且一个长 turn 锁死整个工作区的资产管理；进行中的 turn 在 turn 边界语义下数据不会错，该锁保护错了对象。**否决**。
- **per-session 隐私覆盖**：「会话 A 发样本、会话 B 不发」的分裂语义无场景支撑；隐私是资产的属性不是会话的属性。**否决**。
- **共享名让位的命名规则（纯时间序或共享恒让）**：共享名跨会话漂移破坏工作区公共词汇表（会话 A 教的表名到会话 B 失效）。**否决**。
- **xlsx 进共享面第一刀**：一文件多 sheet 的条目映射与 replace 时 sheet 集合 diff 两个新复杂面，为低频格式买单；私有面支持与一次性导出是现成替代路径。**否决**——启动门槛与私有面 sheet 选择粒度定形联动。
- **拖放添加（接窗口级 onDragDropEvent 路由）**：需把 drop 转发接进 shell 的单路由共享面，且原生接管下 DOM 无 dragover、高亮预览不可得；为低频管理面改窗口路由收益不抵。**否决**。

## Consequences

- **实施切分：机制与模态面板一票交付**——互为入口，拆票必出不可验收中间态。
- **校准 ADR-0137**：Decision 4 的「共享位置大文件的快照成本与现状手动 ingest 同款（会话树内落盘，不碰用户目录与共享位置）」收窄——工作区数据集面的源物化进工作区 store（内容寻址、硬链接），会话树内落盘仅剩会话私有入口；read_* 全路径放行与程序化快照管道不变。
- 引用解析面扩共享引用一类：共享数据集名是一等表名引用（非 read_* 字面量路径），preflight 的引用解析与 stale 检查须识别，ADR-0080/0088 的 read_* 字面量白名单语义不变；沙箱 attach 集扩为共享（惰性）、私有源与 result mirror。
- recipe 事件家族扩共享挂载记录（Decision 9 三元组），与 SourceLifecycleEvent（ADR-0040）家族同层。。
- **后补面与启动门槛**：agent 提升工具（门槛：agent 在多会话反复重算同一转换）；result_N 提升为共享数据集（门槛：用户反复手动导出 result 再拖回）；xlsx 进共享面（门槛：共享需求出现，且私有面 sheet 选择粒度先定形）；卡片注入分级（门槛：数据集多到全卡注入挤占上下文）。
- 私有面独立缺陷：xlsx 整文件全 sheet 导入无选择粒度，留独立票，不随本决策。
- 非目标：跨工作区共享、私有大源物理去重（Decision 12 定性为使用错误）、agent 提升与 result 提升的入口设计。
