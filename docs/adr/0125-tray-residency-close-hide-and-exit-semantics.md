# 托盘驻留：关窗藏窗语义、可用性降级与朴素退出

## Decision

1. **关窗即藏窗，托盘为唯一唤回与退出通道。** `CloseRequested` 一律
   `prevent_close` 并隐藏主窗口（Windows 附加跳过任务栏），不按回合状态分叉——
   语义可预测优先于条件精细化。退出唯一入口为托盘菜单 Quit，走 `app.exit(0)`
   原生运行时收尾，不拦截 `ExitRequested`、不设退出确认；窗口几何落盘与托盘
   图标清除依赖运行时既有钩子。

2. **托盘可用性降级：创建失败则关窗恢复为退出。** 托盘构建结果存应用态布尔；
   不可用（如无托盘宿主的 Linux 环境）时关窗分支改为真退出，杜绝「窗口已藏、
   托盘不存在、退出通道消失」的失联路径。可用性缺失不阻断启动、不视为错误。

3. **托盘菜单为会话速查面，重建于点击时。** 菜单结构：最近会话（禁用头 + 3 条）+
   更多子菜单（次近 10 条）+ 新会话 / 打开主窗 + 退出；数据与会话列表同源，
   条目为展示名单列（会话无项目归属概念，不设双列）。菜单
   内容在托盘点击时重建（后台扫描 + 节流），不维护常驻软更新路径。
   - **被 #1145 校准**：重建触发点由「任意点击」改为「悬停进入与左键点击」——
     右键触发的重建与 Windows 菜单显示竞态（`set_menu` 替换正在显示的菜单句柄
     会立即关闭菜单，首次右键闪现即灭）。菜单结构、节流与「不做常驻软更新」不变。
     Linux 上限：tray-icon 的 GTK 后端不派发任何图标事件，悬停与左键触发均
     不生效，菜单仅有启动首填。

4. **左键唤窗、右键菜单。** 禁用「左键弹菜单」默认，左键单击显示并聚焦主窗口；
   菜单内「打开主窗」为托盘点击行为碎片化平台的显式兜底。

5. **托盘动作与侧栏动作对等。** 会话项点击经类型化事件转入既有恢复通道（载荷为
   持久化路径，会话身份由前端生成），新会话项走既有建会话流；托盘不引入侧栏
   之外的任何会话语义，已开会话点击幂等（唤窗并切换至该会话，不另起实例）。

6. **托盘文案跟随应用语言偏好。** 双语文案表镜像 locale 偏好三态（跟随系统时
   检测系统 locale），不引入第三语言。

## Context

应用是长回合 agent 会话工具：回合执行所有权在后端进程与外部 CLI，但审批交互面
在 WebView——真销毁窗口会把驻留变成回合卡死，藏窗保活是唯一可行驻留形态。此前
关窗即进程退出，进行中回合被杀、恢复通道消失。单实例守卫已在（二次启动聚焦既有
实例），但其回调缺 show——藏窗态下二次启动视觉无响应，与藏窗语义存在缺口。

## Why

1. **驻留动机是护回合，不是常驻品牌位。** 关窗杀回合是真实体验缺口；快速唤起、
   状态展示、通知承接均被既有面覆盖，托盘只做不可替代的驻留与唤回。
2. **可预测语义优先于条件精细化。** 无条件藏窗 + 唯一退出通道零心智负担；按回合
   状态分叉需要跨运行时的在飞判定新状态面，且用户无法预测单次关窗行为。
3. **失联路径是本决策唯一灾难面。** 托盘缺失平台上藏窗等于失联；以极小的状态面
   换掉最坏后果，成本不成比例地低。
4. **点击时重建即恒新鲜。** 菜单仅在点击时可见，重建时点即消费时点；常驻软更新
   （就地改文本防打开中菜单被关）为高频状态变更场景而生，会话列表变更频率不构成
   该需求。
5. **不拦截退出路径是最短正确路径。** 退出三态分类为重启流与进程旁路清理而生，
   两者均不存在；预防性幽灵图标处理所依赖的旁路同样不存在，留人工验证。

## Considered options

- **条件驻留（回合在飞才藏窗）**：需跨运行时统一在飞判定，单次关窗行为不可预测。
  **否决**。
- **驻留设置开关**：零用户诉求，先例为待真实反馈再裁。**否决**。
- **菜单常驻软更新**：为高频用量刷新场景的机制，会话列表低频变更不构成需求。
  **否决**。
- **macOS 专属模板图标**：需新美术资产，主平台无此概念，观感落差留后续增强票。
  **否决**。

## Consequences

- Windows 托盘幽灵图标不在代码层预防——退出走原生运行时收尾、无进程旁路路径，
  为发布前人工验证项。
- macOS 以应用图标直挂菜单栏，彩色图标观感落差存在；专属模板图为后续增强，
  门槛是观感反馈。
- 藏窗驻留保持 WebView 保活，后台内存驻留为接受代价；驻留设置开关待真实用户
  反馈再裁。
- 单实例二次启动回调的 show 缺口随本决策闭合，藏窗态二次启动可唤起。
