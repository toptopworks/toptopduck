# 工具审批:分级模型 + 内置文件系统可达性锁定

## Decision

工具调用在网关层（ADR-0076）实行**分级审批**：(1) 内置只读工具（探索 / describe / 采样）与物化**放行**（物化仅 in-DB，无文件系统 / 网络 egress）；(2) **内置文件系统可达性锁在会话源集 + 工作临时目录**（源文件只读）；(3) 外部 MCP 工具**默认逐次确认**，可选「始终允许」升级为**会话级信任**（信任态不进 recipe，resume 归零）；(4) **授权模式为会话级姿态**：默认逐次确认，可经 composer 入口切换为**免确认**（外部工具调用全部自动放行），会话级有效、resume 回默认、不进 recipe、UI 以警告色标注——「始终允许」（按工具会话信任）与授权模式正交，前者在默认模式下减摩擦。审批打断是 app 的 UI 打断点：外部运行时的调用命中确认时在网关挂起等待用户。

## Context

ADR-0079 把能力边界降位后，强制点挪到工具面。ADR-0029 定「仅 LLM 推理联网」与 key 不出 Rust；外部 MCP 工具引入后联网边界需改写（ADR-0076 已做）。内置引擎的文件系统可达性自 issue #25 悬而未决（DuckDB `disabled_filesystems` 实例级全局且不可逆，read_* 沙箱无界）；agent 模式使该面急剧扩大——agent 可自发构造 `read_csv` 路径。

## Why

1. **分级信任匹配风险分级**：in-DB 操作无 egress，放行不损安全不加摩擦；外部工具能力不可知（网络 / 文件 / 副作用），逐次确认是最小诚实机制；「始终允许」给高频场景出口，会话级有效框定爆炸半径。
2. **内置 FS 可达性锁源集 + 临时目录**：了结 #25 方向——引擎仅可达用户主动交给会话的数据与自己的 scratch；`disabled_filesystems` 的不可逆由「per-session 独立引擎实例（ADR-0027 已有）+ 网关层路径白名单」绕过。
3. **网关挂起审批仅在 ADR-0076 拓扑下可行**：一切调用经网关，外部运行时不例外；运行时直连 MCP 则审批不可言。
4. **信任态不进 recipe**：recipe 是工作集描述（ADR-0034），审批是机器 / 会话级安全状态；混入则移植性破（目标机器信任边界可能不同）。
5. **免确认 = 显式用户主权**：闸门的价值在默认姿态（逐次确认）；用户显式切免确认是知情决定，禁止的是静默放宽——与 ADR-0029「不变量 vs 配置项」同谱系（免确认是显式会话操作，非埋设配置）。会话级 + resume 归零框定爆炸半径。

## Considered options

- **启用即全信任（无逐次确认）**：「LLM 决策 + fetch 类工具」的数据外泄路径无拦截，ADR-0029 信任模型实质废止。**否决**。
- **逐次全确认（含内置）**：单轮数十次调用 = 数十次打断，agent 循环不可用。**否决**。
- **信任态持久化（进 recipe / app-config）**：移植性风险 + 跨会话信任泄漏。**否决**——会话级足够。
- **免确认模式默认开启 / 持久化**：静默或永久放宽信任模型。**否决**——默认逐次确认，免确认是显式会话级操作。
- **三档授权模式（只读类外部工具自动放行）**：须 app 对任意第三方工具做能力类声明，声明不可靠——正是 ADR-0079 明确否决的能力类审计路径。**否决**。
- **内置 FS 全开放（任意路径）**：agent 可自发读取任意文件载入工作集，再经外部工具外发，形成 egress 链。**否决**。

## Consequences

- **了结 issue #25**：方向 = per-session 引擎实例 + 网关路径白名单（源集只读 + 临时目录读写）；`disabled_filesystems` 的全局性不再构成障碍（实例级隔离本已有，ADR-0027）。
- **校准 ADR-0029**：联网边界陈述改写（ADR-0076 已做）；「key 仅 keychain、解密后仅存 Rust」不变量不变。
- **延伸 ADR-0011**：隐私披露覆盖工具面（会话启用的外部工具骑审计）。
- **未决「审批 UI 形态」被 ADR-0083 闭合**：定为流内审批卡片（pending 态轨迹条目 + 允许一次 / 始终允许 / 拒绝三按钮），非窗口模态。见 ADR-0083。
- **未决「始终允许」粒度闭合**：按工具（`server::tool`）、会话级——同工具不同参数共享信任；参数模式粒度 v1 不做（匹配语义复杂、用户心智负担高）。
