# 多会话导航：左会话栏取代顶栏 tabs（三栏 shell + 保活切换 + 显式关闭）

> 部分被 [ADR-0072](./0072-sidebar-search-and-grouping-mode.md) 修订：行 53 搜索框否决**推翻**（持久化列表无上限，搜索解决定位）/ 行 72 时间分组默认**改为 flat + time 可选** / New 按钮不再实心（栏顶改为品牌标题行 `TOPTOPDuck` + New icon + 融合背景）/ 行 15 active 整条 teal 填充**改为浅 tint + 左 2px 条**（与 New 按钮视觉统一）。详见 ADR-0072 Consequences。

## Decision

多会话导航从 ADR-0046 的「单窗 + 顶栏会话 tabs」改为「单窗 + **左会话栏**」，shell 由两栏（0045）扩为**三栏**：

- **最左 = 会话栏**（常驻、可折叠）：列所有持久化会话（名 + 时间 + working set 摘要），承载**切换**（点条目 → 右侧换活跃会话）与**新建**（栏顶「+ 新建会话」）。选中态高亮当前活跃会话。
- **中 = thread rail**（0045 / 0047 / 0054）：轮次卡 + 源事件标记条，不变。
- **右 = workspace**（0045 / 0057）：结果 / Schema / 工作集 tabs，不变。

**会话切换 = 非活跃会话保活**（CSS `hidden`，复用 ADR-0051 的 per-tab 组件 + hidden 保活机制）——切走不卸载、切回瞬时、无 resume 重放。**关闭会话 = 用户显式动作**（左栏条目关闭 → 落 recipe + 卸载 DuckDB 实例 + `removeQueries`，复用 ADR-0046 / 0055），切走 ≠ 关闭。保活会话总数超阈值（ADR-0046 软上限）→ 左栏非阻塞内存压力提示。

**顶栏保留极细**（~40px）：当前会话名（**只读**，命名走左栏弹菜单）+ Settings 图标（BYOK / 主题 / i18n）+ 软上限 badge。新建会话、resume 进度、turn 反馈**均不归顶栏**（分归左栏顶部 / 工作区 / QuestionBar）。

**会话栏与 rail 的视觉分离三信号**：(1) **异色分层**——会话栏为导航 chrome（沉色背景）、rail + workspace 为工作区（主背景）；(2) **逆向宽度**——会话栏窄（~220px，会话名短）、rail 宽（~320px，承载逐字提问截断，ADR-0039 身份句柄要辨识度）；(3) **选中态分流**——会话选中 = 整条背景填充，轮次 viewedResult 选中 = 左侧色条。

**取代 ADR-0046 的「顶栏 tabs」导航决策**；**保留** 0046 的关 tab 落 recipe / 软上限 / 重开 resume / 单 webview 低内存语义——仅载体从 tabs 迁到左会话栏。ADR-0045（rail/workspace 分离）不变。

## Context

ADR-0046 定「单窗 + 顶栏会话 tabs」（浏览器 / VS Code 心智），并显式**否决** β（单窗 + 最左会话侧栏，理由：第三持久栏与两栏决策冲突、偏聊天范式）。本 ADR 推翻该否决。

触发链：先确认 0046 **漏了「打开一个当前未在 tabs 里的持久化旧会话」的入口**——0046 定义了新建（`+`）/ 关 tab（落 recipe）/ 切 tab / 重开 tab（resume），却从未给「从持久化找回旧会话」的触发入口，导致关掉的会话无处再开、0046/0034「关 tab 不销毁、可 resume」的承诺兑不了现。补这个入口时，用户明确偏好「Chat 风格（如 ChatGPT）的左右布局」（常驻左会话栏，非浮层 / 抽屉）。

两个 ADR-0046 写作时未充分权衡的新权重：

1. **2026 年「左栏会话列表 + 右侧对话」的 Chat 风格已成 AI 对话产品的默认心智**（如 ChatGPT），非技术用户（ADR-0001）对其熟悉度已反超浏览器 tabs——0046 当年「tab 是浏览器心智（用户天天用）」的判断需重新权衡。
2. **产品交互范是 AI 对话**（自然语言提问 + AI 回答），ADR-0045「对话流是主轴，不是表」本身就是聊天范式；shell 外壳应向 Chat 风格靠拢，而非 0046「避开聊天范式」。

右侧内部组织选定「保 0045 rail/workspace 分离、不内联」——否决 Chat 风格的纯内联对话流：本项目分析轮次产出 `result_N` 宽表（几十列）+ Vega-Lite 大图（ADR-0016/0033），内联进对话流 3-5 轮即撑到无法导航、提问栏被推下视口（ADR-0045 Why#2 原始理由）；ChatGPT 不踩此坑因其回答是文本 + 小表格 / 小代码块。**内容形态不同，照搬内联撞领域硬墙**。结论：「Chat 外壳 + 工作台内核」。

## Why

1. **Chat 风格心智 2026 普及**（如 ChatGPT，0001 熟悉度反超 tabs）——0046 写作时的外部环境假设已变，β 否决理由之一「偏聊天范式」在新心智下反成产品身份的契合点。
2. **兑现 0046/0034 持久化承诺**——左栏常驻列表是「打开任意旧会话」入口的唯一自然形态；浮层 / 抽屉发现性弱（中间方案，被否决），常驻才让「关掉不销毁、随时找回」可兑现。
3. **保 0045 不内联**——宽表 + 大图撑爆对话流是领域硬约束（0045 Why#2），非偏好；「外壳（会话栏）+ 内核（rail/workspace）」分离让 Chat 心智与工作台渲染两全。
4. **保活切换兑现 0027/0046 多会话并行投资**——「多会话并行隔离 + 对比多数据集」是 0046 反复强调的价值；保活让切换瞬时、对比场景可用，卸载切换每次 eager resume 重放（可能数秒至数十秒）使对比场景不可用、背叛 0046 核心。
5. **显式关闭守语义干净**——切走 ≠ 关闭（用户只是看别的，没想丢这个），关闭才落 recipe 归档；隐式卸载（LRU）违 ADR-0017 诚实 + 非技术用户困惑。
6. **极细顶栏留全局 chrome 的家**——Settings（BYOK 是 onboarding 必经）/ 软上限是全局的，砍顶栏则碎片化；Chat 风格外壳本就有极细顶栏，保留一致性。

## Considered options

- **顶栏 tabs（ADR-0046 原决策）**：被取代，理由见 Context / Why。原否决 β 的「偏聊天范式」在新心智下失效、「第三持久栏与两栏冲突」由可折叠 + Chat 风格外壳价值压过。
- **左会话栏 + 右内联对话流（连 0045 一起推）**：宽表 + 大图撑爆对话流（0045 Why#2 领域硬约束）。**否决**。
- **左侧抽屉 / 浮层（非常驻，中间方案）**：发现性弱于常驻；用户明确要 Chat 风格的常驻布局。**否决**。
- **切走即卸载（单时刻单实例）**：多会话对比场景不可用（切回每次 resume 重放），背叛 0046 核心。**否决**。
- **保活无上限 / LRU 自动卸载最久未用**：撞 ADR-0008 低内存 / 隐式行为违 0017 诚实 + 非技术用户困惑。**否决**——要卸载就显式（用户点关闭）。
- **砍掉顶栏**：Settings / 软上限碎片化到左栏 + 浮层，失 Chat 风格外壳一致性 + 全局操作无家。**否决**。
- **粗顶栏（工具栏式）**：偏 Excel / PowerBI 工作台，违已定的 Chat 风格外壳。**否决**。
- **新建会话放顶栏**：与左栏「会话进出唯一区」重复。**否决**——新建归左栏顶部。
- **顶栏会话名可点击编辑**：与左栏弹菜单命名双入口（DRY 违反）。**否决**——顶栏只读、命名走左栏。
- **LLM 摘要当会话名**：会话级失真 + 增 LLM 调用；首源名是稳定辨识锚。**否决**。
- **搜索框**：软上限控规模，v1 YAGNI。**否决**。
- **会话栏与 rail 同色分层**：三栏混淆（chrome 与工作区不分）。**否决**。
- **选中态都用左侧色条**：会话选中需更强信号（整条填充），色条弱。**否决**。
- **hover `×` 删除**：易误点。**否决**。
- **删除无确认 / 删除 = 关闭（不删 .duck）**：不可逆未守诚实（0017）/ 清理需求未兑现。**否决**。

## Consequences

- **取代 ADR-0046「顶栏 tabs」导航决策**：载体 tabs → 左会话栏；0046 关 tab 落 recipe / 软上限 / 重开 resume / 单 webview 低内存语义**保留**。ADR-0046 待在顶部加「被 0060 取代」可发现性标记。
- **保 ADR-0045**：rail / workspace 不变；新增最左会话栏 = 整体三栏（会话栏 + rail + workspace）。
- **延伸 ADR-0051**：per-tab `<SessionPane key={sid}>` + 切换 `hidden` 保活 + 关闭 `removeQueries` 机制**不变**；「tab」措辞重映射为「左栏选中态 / 非活跃会话」。**0051 措辞待顺（open item）**。
- **延伸 ADR-0055**：「关 tab in-flight」→「关闭会话 in-flight」，语义不变（fire cancel + 立即 removeQueries + recipe 不含 cancelled turn）。**0055 措辞待顺（open item）**。
- **延伸 ADR-0054**：rail 可折叠 + 会话栏可折叠 = 三级折叠退化（窄窗逐级收）。三级折叠交互见 ADR-0054。
- **延伸 ADR-0038**：「上次活跃会话」`last_session_id` 入 app-config preference（启动 resume 用），与窗口几何 / 上次导出目录同档（路径指针、无用户数据值）。
- **未决（留视觉打磨期）**：
  - **顶栏视觉细节**：异色方向（会话栏比工作区更深）、app 名最终去留、会话名只读确认（顶栏已定只读，视觉细节留打磨）。
  - 其余会话栏条目 / 顶栏布局 / 删除会话已决（见上 Consequences）；三级折叠见 ADR-0054；resume 反馈 / 启动语义见 ADR-0061。
- **CONTEXT.md 不动**：会话栏 / 保活 / 显式关闭是 UI 导航与生命周期实现，不引入领域术语（「会话」「resume」已在 CONTEXT.md）；「上次活跃会话」是 ADR-0038 app-config preference，非领域概念。
- **被 ADR-0061 否决（last_session_id）**：本 ADR「延伸 0038 last_session_id」被 0061 否决（启动改 Chat 风格不 resume、不读 last_session_id）。见 ADR-0061。
- **会话栏条目内容 + list_sessions 元数据（已决，闭合 open item）**：主行 = 会话名（用户命名优先；默认名 = 首源名，如 `orders.xlsx`）；副行 = 首源名 + 轮数 + 最后修改时间；Chat 风格的时间分组（今天/昨天/前 7 天/更早）；最后修改倒序；搜索 v1 YAGNI（软上限控规模）。`list_sessions` 元数据 = `{ session_id, display_name, last_modified_at, source_summary（首源名+源数+轮数）, format_version }`——全在 recipe（0034），零新持久化。
- **顶栏布局细化（已决，闭合 open item）**：~40px 左 = 会话栏折叠切换 + app 名（v1 倾向省）；中 = 当前会话名（**只读**，命名走左栏弹菜单）；右 = Settings（BYOK / 主题 / i18n）+ 软上限 badge。新建会话、resume 进度、turn 反馈**均不归顶栏**（分归左栏顶部 / 工作区 / QuestionBar 0059）。
- **命名 / 删除会话（已决，新增 gap）**：会话三态——活跃 / 保活（实例驻留）/ 关闭（落 recipe + 卸载 + .duck 保留，0046 / 0055 / 本 ADR）/ 删除（删 .duck 不可恢复）。入口：左栏条目 → 弹菜单（重命名 / 关闭 / 删除 统一入口，Chat 风格）。删除 v1 做 + 强确认（明确不可恢复）+ 删打开会话先关闭 + 删除后退新会话空态。
- **三级折叠**：见 ADR-0054（rail 折叠 + 会话栏折叠 = 三级手动折叠退化，延伸 0054）。
- **被 ADR-0063 精确化**：本 ADR「删打开会话先关闭」隐含「关闭同步」假设；实际 close IPC resolve ≠ canonical key release（key 在 `Session::Drop` 释放）。0063 定「关闭」走等待变体（等 key release），订正此处的同步假设。见 ADR-0063。
