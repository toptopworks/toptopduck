# 运行时架构:双运行时 + app 所有的无状态引擎 + MCP 网关

## Decision

系统支持两种并存且可换的**运行时（Runtime）**形态：**内置**（Rust agent 循环，由活跃 BYOK 档案驱动）与**外部**（app 拉起的第三方 CLI agent 进程）。运行时是**无状态引擎**：不持任何权威会话状态——thread、窗口、recipe 全归 app；进程存活只是传输层优化。工具面由 **app 侧 MCP 网关**统一聚合：内置 DuckDB 工作集服务器与**启用的**用户配置外部 MCP 服务器归一（技能的 MCP 引用为声明性元数据，所指服务器须启用方可用，见 ADR-0106）；外部 MCP 工具的稳定身份是 `mcp__<server_slug>__<tool>`（`server_slug` = display_name 的 ASCII slugify，空则 `server-<id 前 8>`，冲突 `_2`/`_3`），消歧多 server 同名工具并让 trace filter（`mcp__` 前缀谓词）一致——该身份作为发现卡片句柄与 `mcp_invoke` 的寻址实参贯通审批与 trace，网关解析前置后路由、发原始 `<tool>` 给 server（外部工具经固定元工具发现面按需可见，取代整表平铺，见 ADR-0105）；内置运行时的 LLM 调用直接带工具面（内置工具直列 + 元工具三件套），外部运行时只连 app 暴露的**单一聚合 MCP 服务器**（经一个携带会话寻址参数的薄桥接进程）。每轮由 app 装配（提问 + 窗口化上下文 + 活跃技能集 + 工具面）喂给运行时，运行时产出执行轨迹与终局答复。运行时可在轮次边界切换，每轮记录运行时出处。

## Context

ADR-0007/0064 定单一 app 内 transpiler 路径：LLM 是无状态 text→SQL 转换器，能力增长绑定 app 内 prompt 工程。该路径无法结构性吸收两类能力：(1) 第三方 CLI agent 已成熟的 agent 循环（多步推理、自纠、生态技能）；(2) MCP 标准下的工具扩展（社区工具面增长远快于 app 内实现）。同时 toptopduck 的护城河——local-first、BYOK、per-session 引擎隔离、recipe 可 resume（ADR-0001/0006/0027/0034）——全在 app 进程内，运行时架构不能以这些为代价。

## Why

1. **双运行时覆盖两条价值轴**：内置 = 零安装、key 不出进程、契约纪律最强；外部 = 借成熟 agent 循环与生态。单取其一失半数用户。
2. **运行时无状态**：如此 resume 才与运行时正交（recipe 重放走引擎不走 LLM，ADR-0035）、切换才无缝（下轮由同一窗口装配）、持久化格式才统一（无双轨第三方会话格式）。
3. **网关是唯一强制点**：物化命名（ADR-0077）、分级审批（ADR-0080）、审计全在网关层；运行时若直连外部 MCP，这些皆不可强制（外部 CLI 进程不可控）。聚合还消灭 per-runtime × per-tool 的 plumbing 组合爆炸。
4. **桥接进程被 CLI 拉起、回连 daemon** 是兼容 MCP stdio 传输契约（server 由 client 启动）的唯一形态；会话寻址随参数，天然 per-session 隔离（ADR-0027）。

## Considered options

- **runtime 所有会话、app 镜像**：resume 依赖第三方状态格式，BYOK 侧需另建一套，领域模型裂成两半。**否决**。
- **混合分治（内置 = app 所有，外部 = runtime 所有）**：resume / 切换 / thread 渲染全双轨。**否决**。
- **运行时直连外部 MCP（app 不聚合）**：审批 / 审计 / 物化强制点全失，plumbing 组合爆炸。**否决**。
- **砍 GUI 转 CLI agent 产品**：可视化 / 结果表 / 工作区资产（ADR-0016/0057）作废，产品身份分叉。**否决**。

## Consequences

- **取代 ADR-0007** 的单一 app 内路径立场：Provider 抽象降为内置运行时的接入层（见 ADR-0081）。
- **延伸 ADR-0027**：多会话隔离从「per-session 内存 DuckDB」延伸到「per-session 网关路由 + per-session 桥接」；引擎资源上限（ADR-0005）不变。
- **延伸 ADR-0056**：IPC 寻址语义不变；新的轮次命令携带运行时出处与技能出处。
- **联网边界陈述改写**：app 主动联网仅 LLM 调用路径与用户启用的 MCP 工具；外部运行时进程自身联网归第三方（校准 ADR-0029，见 ADR-0080）。
- **新领域术语**：运行时 / 工具 / 技能 / 执行轨迹 / 技能生命周期事件已入 CONTEXT.md。
- **未决（实施期）**：桥接进程分发形态（随安装包 sidecar / 独立包）、网关进程 per-session vs 共享边界。
- **被 ADR-0108 校准**：联网边界的第三方归属子句延伸到用户注册 CLI 工具的子进程——网关代拉起，其网络行为归工具自身。
- **被 ADR-0110 校准**：装配元组中「活跃技能集」读作「挂载集元数据索引 + 激活集正文」；工具面新增条件成员 `activate_skill`（挂载集非空时）。
