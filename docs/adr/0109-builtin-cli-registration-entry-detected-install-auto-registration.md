# 内置 CLI 注册项：随版发行定义经本地安装检测自动注册，配套技能开箱即用

## Decision

1. **第二来源类：单注册表、来源二分。**「CLI 注册项」成为属概念，来源二分——**用户 CLI 注册项**（ADR-0108 全部语义）与**内置 CLI 注册项**（新增）。内置项的定义（可执行程序、argv 模板、参数表、描述、env）由 app 策展、随 app 版本发行，与用户项同表共存；工具级语义逐位同构——分级审批、审计、调用入轮次执行轨迹、直列进工具面；差异仅在生命周期管理（不可删除、名字锁定，见 Decision 2）。自动注册完成即**默认启用**；零配置不等于零审批——0080 分级审批原样，来源不作审批判据。

2. **可编辑、名字锁定、基线追踪。** `name` 是稳定身份——配套内置技能按名引用、审批信任键挂名、防撞校验围绕它——不可编辑；其余字段（可执行程序、argv 模板、参数表、描述、env）全开放编辑。app 版本更新逐条对账：条目与基线定义一致（用户未编辑）→ 静默升级为新定义，基线前移；条目与基线不符（用户编辑过）→ 原样保留，app 永不覆写用户编辑；被保留的编辑条目提供显式「恢复内置定义」动作，此后升级重新跟随。

3. **检测语义：PATH 解析，不 spawn。** 检测 = 对内置定义声明的可执行程序做 PATH 解析（不 spawn——spawn 可能触发工具自身副作用，如更新检查、配置初始化）；扫描范围 = 仅 app 随版的内置定义集，不做泛 PATH 扫描；时机两个——app 启动自动扫描（命中即静默自动注册）与设置页手动重扫；检测态是计算快照，不落持久化。权威兜底是 0108 调用时解析：运行中工具被卸载，调用返回结构化工具错误，条目悬空保留，重装自动复效。检测只决定「进不进工具面」，不决定「能不能调用」。自动注册无打扰——无弹窗、无引导、无安装动作（0108 对自动安装的否决原样有效）。

4. **v1 策展清单与排除线。** 三项：OfficeCLI（Office 文档处理与生成）、pandoc（万能文档转换）、Python 解释器。排除线：**命令拼装器（shell 形态组装任意命令）不内置**——那是 ADR-0108 真正否决的形态。解释器项不打包任何运行时：出厂不携带解释器，未安装则条目休眠，「默认空、装机零新增执行面」仍成立——它是「参数恰为自由代码」退化解的策展化，指向用户自装解释器。解释器项传值走 `file` 通道（代码写入会话工作临时目录的脚本文件，argv 收路径）；库生态（pandas 等）归用户机器，技能不承诺库在场。遴选标准就此立住：非交互批处理、argv 形状稳定、补真实能力缺口、用户可自行安装。

5. **配套技能一律 app 自撰、随版发行。** 每个内置项的配套技能由 app 策展撰写并随 app 版本发行，与 app 系统提示同属策展信任域。第三方工具自带的 `SKILL.md` 不被自动吸纳——技能正文的归宿是系统提示，检测到可执行文件即自动导入第三方文本是无人审阅的注入通道；且 `SKILL.md` 与可执行程序的位置关系无规范可依，自动发现不可靠。用户需要者走既有手动导入流程（显式用户动作，信任语义干净）。

6. **内置技能生命周期：自动带入，单轴关闭。** 内置技能进全局技能库、带来源标记、**不可删除**，可编辑并套用 Decision 2 的基线语义。新会话起步时，对应内置 CLI 注册项处于**检测到 + 启用**的，其配套技能自动进入该会话的活跃技能集——这是起步**初始状态**，不产生 Mount 生命周期事件（0086 的事件只记用户驱动突变）。会话内卸载有效（正常事件、会话级），下个新会话按当前状态重新带入；不设机器级永久屏蔽的第二开关——永久关闭 = 禁用对应工具，技能在场是工具状态的派生，不是独立策展轴。工具禁用则技能不再自动带入，引用语义走 0106 诚实降级。

7. **冲突与重复。** 内置项的 `name` 与既有用户项相撞：内置项**退让**——不自动注册、不改用户项，设置页呈现冲突态，用户处置（改名或删除自己的条目）后下次扫描自动补注册；注册表中用户项是先来者，策展方不插队。同一可执行程序对应多个注册项：允许并存、不去重——各有名字与信任键，去重是替用户做决定。0108 的注册名防撞校验（不得撞内置工具名、`mcp__` 句柄前缀、元工具名）追加一类：**不得撞内置 CLI 注册项名**。

8. **审批卡按需展示 `file` 传值内容。** 审批卡默认渲染将被执行的完整 argv（ADR-0108 Decision 7 原文不变）；含 `file` 传值的调用（解释器项是首位消费者），卡片提供传值文件内容的**按需查看**——默认面仍是 argv，查看内容为用户主动展开的低频动作。临时脚本文件于调用结束即删，展示内容于审批发起时随值捕获。

9. **注册表载体 = app-config，一切写入经后端读改写命令。** CLI 注册表（用户项与内置项的持久化状态）住 app-config、与 MCP 注册表同居；内置项的定义本体不持久化——它是 app 版本资产。写入纪律：用户增删改、自动注册、基线升级、启用态切换，一律走后端读改写命令（config 写锁内 read-modify-write，与 `upsert_mcp_server` 同型），返回更新后的全量配置供前端同步；`set_app_config` 全量写继续承载其余偏好字段。后端发起写集中于启动窗口——自动注册与基线升级发生在前端首次加载配置之前；手动重扫经 IPC 返回即同步；配置变更经事件推送，前端快照保鲜。

## Context

ADR-0108 确立 CLI 工具为外部工具第二来源，留下两处缺口：持有命令行工具的用户仍需走一遍注册表单，能力扩展有摩擦；「预设注册表（一键注册）」被记为后续。与此同时，命令行生态存在一类为 agent 设计的单二进制、非交互工具——文档处理、格式转换、文本提取——恰好补上 DuckDB 原生不覆盖的能力面；数据清洗与转换的刚需则让通用解释器的退化解（参数 = 自由代码）值得从用户自行注册晋升为策展位。

0106 在默认启用上为「未来的批量安装入口届时自定默认」留了口子；0086 的技能注入与生命周期语义现成，配套技能无需新机制。本 ADR 把预设注册表的缺口合上：形态不是注册表单的一键确认，而是 app 随版的定义在检测到本地安装时自动注册，开箱即用。

## Why

1. **自动注册不是二次表达意图**：用户安装该可执行程序已是集成意图，再要一遍确认是对同一意图的二次表达（0106 Why 4 同理）。不与 0108「默认空」冲突——默认空禁止的是出厂即注册未装的工具；不碰「自动安装」否决——app 不下载、不代装，只登记已装之物。
2. **不可删消灭抑制态跟踪**：可删除的自动注册项需要「删除 = 永久抑制」语义（否则再检测复活、用户的「不要」被推翻）；不可删从结构上消灭该状态，关停收敛到禁用单轴（0106 禁用为绝对权威）。「不想要」与「暂时没装」由禁用 / 悬空两轴正交表达。
3. **可编辑 + 名字锁定是定制与身份的最小分界**：逐机定制（env、参数细节）需要出口，锁死定义会把全部定制推给「自己再注册一个」；名字是多方锚点（技能引用、信任键、防撞），一放编辑则引用悬空、信任无声重置——锁名字、放其余。
4. **基线追踪是「用户编辑不蒸发」与「策展定义能演进」同时成立的唯一形态**：永不覆写让老机器定义静默腐烂；强制覆写让用户编辑蒸发；按基线对账把两种状态精确分开。
5. **PATH 查找不 spawn**：存在性判定零副作用、毫秒级；检测时 spawn 验证会在用户未授权的场景触发工具自身行为。检测只是进面资格，调用时解析才是权威兜底——两层在 0108 已经分开。
6. **app 自撰技能是信任边界要求**：技能正文的归宿是系统提示，自动吸纳第三方文本是无人审阅的注入通道；app 自撰与系统提示同属策展信任域。自带 `SKILL.md` 的位置发现不可靠是第二理由。
7. **自动带入是开箱即用在技能侧的兑现**：手动挂载意味着每个会话重复一步；技能在场由工具状态（检测到 + 启用）派生——派生状态不构成独立策展轴，0106 的单轴纪律在此延伸。
8. **解释器进清单不改否决面**：不打包运行时（0108 否决项原样）、未安装则注册集为空（默认空成立）、审批走 0080 分档（来源不入判据）；真正排除的是 shell 拼装器——shell 语法、注入面、进程生命周期失控。
9. **app-config 而非独立载体**：注册表是用户意图（启用态为绝对权威），非观测快照——0096 的 app-data 例外不适用；0106 已否决注册表拆分（严格读 / 导出 / 回滚仪式翻倍）；后端发起写的碾压风险由既有读改写命令模式解决（后端写集中启动窗口 + 事件推送保鲜），分裂载体动机不成立。

## Considered options

- **一键确认注册（检测后提示用户确认）**：对同一意图二次表达；开箱即用差一步。**否决**——检测即自动注册。
- **内置项可删除（删除 = 永久抑制）**：需跨扫描周期跟踪抑制态，复活与抑制的冲突语义复杂；禁用已覆盖「不要」。**否决**——不可删，禁用为唯一关停轴。
- **内置项不可编辑**：逐机定制被推给「自己再注册一个」，内置项退化为推荐位。**否决**——可编辑、名字锁定。
- **app 更新强制覆写定义**：用户编辑无声蒸发。**否决**——基线对账，改过保留。
- **app 更新永不升级已注册条目**：老机器定义永久停在旧版，工具版本变化即静默坏掉。**否决**——未改随版升级。
- **检测时 spawn 验证**：触发工具自身副作用（更新检查、配置初始化）。**否决**——PATH 查找。
- **泛 PATH 扫描发现工具**：检测集 = app 随版的内置定义；推测式发现不在本域。**否决**。
- **检测时自动导入工具自带 `SKILL.md`**：无人审阅的第三方文本进系统提示；`SKILL.md` 与可执行程序的位置无规范可依。**否决**——app 自撰，第三方走手动导入。
- **内置技能手动挂载**：技能侧开箱即用落空，每会话重复挂载。**否决**——检测到 + 启用即自动带入。
- **机器级永久屏蔽某内置技能（第二开关）**：分裂策展轴；永久关闭已可由禁用工具表达。**否决**——单轴。
- **内置命令拼装器（shell 形态）**：shell 语法、注入面、进程生命周期失控——ADR-0108 真正否决的形态。**否决**。
- **打包解释器 / 承诺库生态**：0108「不打包解释器」否决原样有效；app 不携带运行时。**否决**——条目指向用户自装解释器，只提供执行面。
- **同一可执行程序多项去重**：去重是替用户做决定；并存无害、信任键各自独立。**否决**。
- **内置名相撞时抢占或改名用户项**：用户项是先来者，策展方不插队。**否决**——内置项退让呈冲突态。
- **审批卡默认展示 `file` 传值内容**：低频动作占据默认面。**否决**——argv 为默认，内容按需查看。
- **来源作审批判据（内置项放宽审批）**：能力类判断；0080 分档与 0108 Decision 7 不变。**否决**——来源仅影响生命周期管理。
- **CLI 注册表独立配置存储**：0106 已否决注册表拆分（仪式翻倍）；后端写入竞态由读改写命令模式解决，分裂动机不成立。**否决**——与 MCP 注册表同载体。
- **注册表住 app-data（仿 0096 探测缓存）**：该例外只保护观测快照；启用态是用户权威意图，删除即失效不成立。**否决**。
- **`set_app_config` 对注册表段做段级跳过**：为工程上不可达的碾压窗（后端发起写集中启动窗口 + IPC 返回与事件推送保鲜）引入新机制，代价大于收益。**否决**。

## Consequences

- **CONTEXT.md 校准**：首段工具箱句补内置来源；「工具」「网关」「CLI 工具」「技能」词条校准；新增「CLI 注册项」（属概念与来源二分）与「内置 CLI 注册项」词条。
- **校准 ADR-0108**：四处——「出厂不注册任何项」读作「出厂无已注册项；app 随版的内置定义经本地安装检测自动注册」；代码解释器退化解晋升为策展内置项（不打包解释器不变）；注册名防撞校验追加「不得撞内置 CLI 注册项名」；Decision 7 审批卡增加 `file` 传值内容按需查看（默认仍渲染完整 argv）。该 ADR 的「注册项」措辞读作用户 CLI 注册项。
- **延伸 ADR-0108**：该 ADR 未决注册表载体，本 ADR 定为 app-config（与 MCP 注册表同居），一切写入经后端读改写命令（Decision 9）；后端发起写集中于启动窗口（重扫路径经 IPC 返回即同步）。
- **校准 ADR-0106**：默认启用新增第四入口类——检测驱动的自动注册，默认启用（意图依据 = 用户自装该可执行程序）；既有三入口与禁用绝对权威不变。
- **校准 ADR-0086**：技能库来源二分——用户（创建 / 导入）与内置（app 自撰、随版发行、配套内置 CLI 注册项）；内置技能于对应项检测到 + 启用时自动进入新会话活跃集——起步初始状态，非 Mount 生命周期事件；身份、`content_hash`、诚实降级语义不变。
- **与 ADR-0079 无校准**：默认行为不变——未安装任何工具的机器注册集为空，能力边界维持默认；扩展路径的第三成员获得策展通道，成员语义不变。
- **工具进程行为归第三方**：内置项策展的只是注册定义；执行仍是第三方进程，其网络行为、常驻子进程归其自身（0108 Consequences 的工具进程条款延伸到内置项）。
- **v1 清单为加法演进**：遴选标准已立（Decision 4），后续增补工具按标准过筛，不重开本 ADR。
- **被 ADR-0110 校准**：Decision 6「自动进入新会话活跃技能集」读作「自动进入挂载集」——起步即可发现（元数据进索引）、不预激活，正文待按需激活（激活免审批）；「起步初始状态、不产生 Mount 事件」语义不变；本 ADR 中「活跃技能集」措辞同读作「挂载集」。
- **留实施期**：检测的可执行程序名跨平台差异（`python` / `python3`）；冲突态与内置 / 用户项差异化的设置页呈现；「恢复内置定义」动作的 UX；审批卡 `file` 传值内容的捕获机制与展示形态；内置技能正文的 i18n；CLI 注册表的 serde 形状（来源属性、基线标记）与配置变更事件推送。
