# 执行轨迹:持久化但可折叠,远窗收摘要

## Decision

轮次的**执行轨迹**是轮次的**持久化子结构**，**按 provider round-trip 分组**（ADR-0103 校准）：每轮 = 可选 thinking（时长 + 模型原始推理，仅运行时提供数据源时存在，否则 honest degrade）+ 可选连接话语（模型在该轮工具批前输出的散文）+ 该轮的工具调用串（探索 / 物化 / 外部工具，各带参数、结果摘要与成败）。thread rail 恒显提问与终局答复，工具调用串与 thinking **按需展开**，连接话语恒显；远窗（ADR-0023/0039）只收（终局答复 + 晋升引用 + 调用数 + 失败概要），**不收全量轨迹**；审计日志留全量。轮次另记运行时出处与技能出处（装配上下文；记激活集，ADR-0110 校准）。

## Context

agent 轮次可发起多次调用（执行级兜底上限见 ADR-0081）。若轨迹与轮次同格（ADR-0028 恒可见 + ADR-0039 逐字截断进窗），40 轮会话的窗口被轨迹撑爆（token），rail 可读性退化；若轨迹不持久化，网关「可审计」承诺（ADR-0076）落空，跨轮失败回溯失据。chat 形态投影（ADR-0103）另要求 assistant 侧复现「thinking—连接话语—步骤」交替节奏，扁平轨迹缺轮边界、散文与 thinking 无承载。

## Why

1. **ADR-0028 恒可见的核是轮次恒可见**；轨迹是轮次的子结构，可折叠不破契约。
2. **数据分析场景 90% 关心答案与结果表**；轨迹价值在审计与回溯，按需展开两全。
3. **跨轮自纠需要的是失败信息**（哪条查询错、为何错），概要级信息密度足够；全量轨迹进窗 token 性价比最差。
4. **recipe 展示部分（ADR-0034）含轨迹**，resume 可复现完整 thread（含展开态的数据源）。
5. **连接话语与 thinking 是文本话语与过程回溯，非数据 payload**；话语本属对话历史，thinking 的回溯价值由参照范式实证（历史会话可展开），成本治理由 posture thought-level 既有入口接管（ADR-0095/0100）。

## Considered options

- **轨迹一等公民、全量追加并进窗**：token 与渲染成本最大。**否决**。
- **轨迹是临时态、不持久化**：审计性失、resume 无轨迹。**否决**。
- **轨迹持久但全量进远窗**：窗口爆炸依旧，仅解决 rail 可读性。**否决**。
- **扁平轨迹 + thinking live-only**：resume 视图失轮节奏与 thinking 回溯。**否决**（事实校准：数据源存在但未接通，见 ADR-0103）。

## Consequences

- **校准 ADR-0028**：轮次条目 = 提问 + 终局答复 + 晋升引用 + 轨迹（可折叠）；恒可见契约由轮次层承担。
- **校准 ADR-0039**：远窗句柄 = 逐字截断提问 + 答复 + 轨迹概要（调用数 / 失败概要）；非 LLM 生成原则不变。
- **校准 ADR-0059**：turn-progress 阶段反馈从 Thinking/Querying 演进为工具调用事件流（轨迹即其持久化形态）。
- **延伸 ADR-0040**：技能生命周期事件与源生命周期事件同构（恒可见、非轮次、进当前状态视图）；轮次记技能出处供审计。
- **CONTEXT.md**：执行轨迹已入词条。
- **ADR-0103 校准**：轨迹由扁平改为按轮分组（含连接话语 + thinking 子结构）；轮次加 `asked_at` / `settled_at` 可选字段（老轮 honest degrade）；ADR-0054 单行截断退役；thinking 接通随运行时数据源边界（内置 anthropic 随 posture thought-level 启用，其余协议 / 适配器 honest degrade）。
