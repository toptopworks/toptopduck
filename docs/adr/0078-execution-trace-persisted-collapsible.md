# 执行轨迹:持久化但可折叠,远窗收摘要

## Decision

轮次的**执行轨迹**（全部工具调用串：探索 / 物化 / 外部工具，各带参数、结果摘要与成败）是轮次的**持久化子结构**：thread rail 恒显提问与终局答复，轨迹**按需展开**；远窗（ADR-0023/0039）只收（终局答复 + 晋升引用 + 调用数 + 失败概要），**不收全量轨迹**；审计日志留全量。轮次另记运行时出处与活跃技能出处（装配上下文）。

## Context

agent 轮次可发起多次调用（执行级兜底上限见 ADR-0081）。若轨迹与轮次同格（ADR-0028 恒可见 + ADR-0039 逐字截断进窗），40 轮会话的窗口被轨迹撑爆（token），rail 可读性退化；若轨迹不持久化，网关「可审计」承诺（ADR-0076）落空，跨轮失败回溯失据。

## Why

1. **ADR-0028 恒可见的核是轮次恒可见**；轨迹是轮次的子结构，可折叠不破契约。
2. **数据分析场景 90% 关心答案与结果表**；轨迹价值在审计与回溯，按需展开两全。
3. **跨轮自纠需要的是失败信息**（哪条查询错、为何错），概要级信息密度足够；全量轨迹进窗 token 性价比最差。
4. **recipe 展示部分（ADR-0034）含轨迹**，resume 可复现完整 thread（含展开态的数据源）。

## Considered options

- **轨迹一等公民、全量追加并进窗**：token 与渲染成本最大。**否决**。
- **轨迹是临时态、不持久化**：审计性失、resume 无轨迹。**否决**。
- **轨迹持久但全量进远窗**：窗口爆炸依旧，仅解决 rail 可读性。**否决**。

## Consequences

- **校准 ADR-0028**：轮次条目 = 提问 + 终局答复 + 晋升引用 + 轨迹（可折叠）；恒可见契约由轮次层承担。
- **校准 ADR-0039**：远窗句柄 = 逐字截断提问 + 答复 + 轨迹概要（调用数 / 失败概要）；非 LLM 生成原则不变。
- **校准 ADR-0059**：turn-progress 阶段反馈从 Thinking/Querying 演进为工具调用事件流（轨迹即其持久化形态）。
- **延伸 ADR-0040**：技能生命周期事件与源生命周期事件同构（恒可见、非轮次、进当前状态视图）；轮次记技能出处供审计。
