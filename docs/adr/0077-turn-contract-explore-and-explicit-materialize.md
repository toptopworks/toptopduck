# 轮次契约:探索查询 + 显式物化晋升,单 SQL 契约废止

## Decision

一轮的执行从「恰好一条 SQL」变为「0 或多次工具调用」。**中间结果仅由显式物化工具调用产出**（晋升进工作集、得 `result_N` 名、受 ADR-0024/0030 上限约束）；**探索查询是 scratch 语义**（轮末即弃、不进工作集、不得名）。MCP 不对工作集暴露裸 DDL（scratch 对象活在轮级寿命命名空间）。outcome 四分（ADR-0028）保持：`result` = 本轮产出一或多个晋升；`textual` / `failed` / `cancelled` 不变；越界拒绝继续骑 textual（ADR-0017 降位见 ADR-0079）。**失败语义**：工具级错误（SQL 报错、审批拒绝、MCP 失败）**回给运行时自纠**；盲重试机制废止（校准 ADR-0005）；传输层瞬时错误仍由 HTTP 重试处理，不上达运行时。

## Context

ADR-0009 定「一次提问 → 一条 SQL → 一个 outcome」，配套物化（ADR-0003/0024）、编号（ADR-0022）、隐式链接（ADR-0010）。agent 循环下，一个提问天然展开为多次查询（筛 → 聚 → 总），单 SQL 契约把多步分析强行拆成多轮，与 agent 形态相悖。但若放任 agent 自由物化，工作集被 scratch 垃圾污染（单轮 8 查询即 8 个 result）；若放任裸 DDL，recipe 重放链（ADR-0034）与引用身份（ADR-0037）失锚。

## Why

1. **显式晋升、自由探索**：用户可见的工作集只留「agent 认为值得保留者」，scratch 轮末无痕；强制点在 MCP 服务端，两运行时行为同构（外部 CLI 无法绕过命名）。
2. **编号语义（ADR-0022）沿晋升顺序自然延续**；recipe 可重建部分记晋升链（SQL + 依赖引用），重放语义不变（ADR-0035）。
3. **错误回 agent**：agent 循环的价值 = 看见错误并纠正（错字段 → describe → 改写）；盲重试与自纠语义重叠，并存只令失败模式翻倍。引擎级护栏（资源上限 / statement timeout）留作 MCP 服务端强制（ADR-0005 降位而非废止）。
4. **outcome 四分保持**：前端错误呈现（ADR-0069）、测试矩阵、持久化契约皆系于此分类；仅 result 含义演进。

## Considered options

- **查询即物化（服务端强制每次查询得 result_N）**：单轮多查询污染工作集。**否决**。
- **内部多查、仅终局引用者物化**：服务端无法可靠判定「最终查询」（外部运行时尤甚）。**否决**。
- **裸 SQL + 退役 result_N**：工作集 = 库中活表，recipe 重放链失效，0022/0024/0030/0037 系列十余处作废，冲撞面最大。**否决**。
- **盲重试保留与自纠并存**：失败语义双轨。**否决**。

## Consequences

- **取代 ADR-0009**；ADR-0010（隐式链接）由 agent 轮内推理天然实现，跨轮重定向语义保留。
- **校准 ADR-0022**：编号按晋升顺序（非按轮序）；单调递增、永不复用不变。
- **校准 ADR-0028**：result = ≥1 晋升；执行轨迹骑轮次条目（见 ADR-0078）。
- **校准 ADR-0005**：盲重试废止；引擎护栏降至 MCP 服务端强制层，资源上限 / statement timeout 不变。
- **延伸 ADR-0025/0041**：换源级联失效的对象从「productive SQL」变为「晋升条目」；stale 派生语义不变。
- 执行级兜底（步数 / 墙钟）见 ADR-0081。
