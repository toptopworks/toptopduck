# 技能调用：激活退役为轮级展开与启用轴闸门

## Decision

1. **激活退役为轮级调用，正文单次展开随历史驻留。** 技能不再有会话级持久激活态。一次调用 = 技能正文在调用点展开、随该轮进入持久历史、随对话驻留供后续轮次复用。调用两方可发起：用户（输入框触发式选择的暂存，提交时物化为该轮调用，ADR-0112 信道延续）与 agent（网关元工具）。重复受益靠历史驻留，无需重新调用；展开不可撤回，与已发出的消息同命运；正文钉住调用时点字节，轮次出处以 `content_hash` 诚记（ADR-0086 纪律延续）。

2. **调用记录归属轮次，与提问同级。** 调用是轮次的输入记录（`name` + 正文 + 发起方 + `content_hash`），随轮次进 LLM 窗口与 recipe 持久化；timeline 技能事件物种（挂载 / 卸载 / 激活）退役，对话 timeline 收缩回轮次与源生命周期事件两族。轮次出处（该轮被什么塑造）即该轮调用记录的名字集。

3. **挂载集降格为发现快照，调用闸门上移机器级启用轴。** 发现快照 = 会话创建时点的启用集（ADR-0118 启用轴 ∩ 注册表、内置者双轴合取维持），会话内不可变，显式入 recipe 持久化；元数据索引随轮次装配注入 = 快照全员统一列出（「已激活者不进索引」规则随激活态消亡）。调用的资格闸门 = 技能处于启用轴；快照外中途启用的技能可经用户调用通道使用——无索引行，agent 自动发现不可达（新会话可达）。

4. **元工具继任：`invoke_skill` 与读门改挂已调用集。** `activate_skill` 由 `invoke_skill(name)` 继任：调用即展开，正文随调用记录进入当轮上下文；免审批继承（闸门即启用轴，论证链更短）；快照非空的轮次才挂（空集条件挂载同构）；查无此名的自纠信号维持。`read_skill_file` 闸门从「挂载 + 激活」改为**会话内已调用集**——轮次调用记录折叠的派生视图，单调增长；已调用集非空的轮次才挂。子智能体维持排除（其技能路径 = agent 定义的技能名标记注入，ADR-0117 不变）。

5. **UI 展示职责随发起方迁移。** 用户调用 = 提问气泡徽章（该轮被什么技能塑造）；agent 调用 = 执行轨迹行（元工具调用本身）；composer chips 只显本轮调用暂存、提交即清；技能选择器只列启用技能；激活徽章、生命周期标记行、chips 的激活真值并集显示全部退役。「生效中技能」的可见性 = 历史本身（调用记录随轮次恒可见），无状态面可堆叠。

6. **format_version v6 → v7，经迁移链升版。** 新调用记录字段与不再落技能事件是前向兼容断点（ADR-0036 纪律）；v6 会话文件经注册的 v6→v7 迁移步骤打开：技能事件原样保留（v7 结构继续认读，新语义不再产生）、挂载折叠物化为发现快照、激活集随激活态退役——旧激活正文从未进持久历史，无处亦无需迁移，名字经快照保持可见、需要时重新调用零摩擦。发现快照随 recipe v7 显式持久化。

## Context

激活态现状是会话级持久子集（ADR-0110 Decision 2）：正文随每轮装配重组装注入于历史之前的前缀区、技能文件每轮从磁盘重读、卸载是唯一出口；composer chips 显示「预激活意图 ∪ 激活真值」。三重后果随会话长度放大：激活单调累积，chips 逐轮堆叠；激活集与文件内容的任何变动都改变提示前缀，KV 前缀缓存自变动点全部失效，其后整段历史按未命中价重读；外部运行时（ACP）路径的激活正文块随每轮出站重发，在外部上下文逐轮累积副本。注入面的其余部分已在此前链路中收敛为「元数据常驻 + 正文按需」（ADR-0110）与「种子 = 启用全集」（ADR-0118），唯独「按需」的落点是持久态而非单次展开。

## Why

1. **前缀恒定是缓存与上下文经济的封顶动作**：调用展开后前缀 append-only——索引块（快照）会话级字节恒定、正文一次付清随历史、无每轮磁盘重读的漂移；持久态方案的每次生命周期变动以「变动点之后的全部历史按未命中重读」计价，越长的会话越贵。
2. **堆叠无滋生土壤**：堆叠的根因是持久态的显示面随会话单调增长；状态本身消亡，显示面随之消亡——比任何显示层收敛都彻底。
3. **多轮复用零摩擦**：正文驻留历史，后续轮次直接可见——「几轮需要同一技能」无需重新选择；agent 的自主复用同理（历史可见 + 索引常驻）。
4. **对 ADR-0110 Decision 2 否决形态的翻案是位置性的，不是窗口化翻案**：当时否决的是「一次性工具结果进**轨迹**」——轨迹不进远窗，磨掉是结构必然。本设计的调用是**轮次输入**，与提问原话同级、同进窗口；其被窗口化磨掉不再是缺陷而是**过期语义**——技能指令与消息同命运，需要时重新调用零摩擦（免审批维持）。「激活指令必须全程有效」是旧设计自设的前提，不是领域要求。
5. **词汇与状态同步收缩**：挂载 / 卸载 / 激活三态机器、卸载唯一出口、激活真值显示面全部退役；三层治理各归其位——启用轴管「能不能调」、快照管「可不可见」、调用管「何时进上下文」。
6. **子智能体排除维持**：调用虽不再是会话突变，开放给子智能体是新增能力面且其技能需求已有定义标记通道覆盖——不搭语义手术的车。

## Considered options

- **仅显示层收敛（chips 聚合或隐藏激活真值）**：生效中的技能不可见、退出通道缺失；每轮重组装与缓存失效照付。**否决**——病根是持久态不是显示。
- **仅手动通道展开化、agent 维持持久激活**：双机制并存、语义永久不对称；agent 侧堆叠与缓存失效照旧。**否决**。
- **调用保留为独立 timeline 事件（物种收缩为单 kind）**：正文钉住须事件携带字节；窗口装配需特判「事件正文挂回轮次」；agent 轮中调用落在进行中轮次之外的时序别扭。**否决**——调用是轮次输入，归属轮次。
- **`read_skill_file` 轮级门（只算本轮调用）**：正文历史全程可见、读面却轮级过期，两层不一致。**否决**——会话内已调用集。
- **调用时读最新文件（延续每轮重读语义）**：前缀字节随编辑漂移破坏缓存；出处对「实际见过什么」撒谎。**否决**——钉住调用时点。
- **v7 拒开 v6 会话文件（无迁移断点）**：打破迁移链自 v0 起任何历史文件可打开的性质；一条 JSON 迁移步骤（透传技能事件、折叠挂载为快照、激活集退役）即可让存量会话续命。**否决**——注册 v6→v7 迁移。
- **子智能体同步开放调用**：能力增益无现实场景压着；扩大嵌套轨迹记账面。**否决**——维持排除，留尾另议。

## Consequences

- **校准 ADR-0110**：Decision 2「激活态持久 + 持续注入」读作轮级单次展开，其对「一次性注入」的否决按本 ADR Why 4 位置性翻案；Decision 3 元工具由 `invoke_skill` 继任（免审批、自纠信号、条件挂载维持）；Decision 4/5 状态机与事件记账退役；Decision 8 外部运行时披露块去正文重发。渐进披露第一层（元数据索引）与第三层（受限读面）维持，第二层读作调用展开。
- **校准 ADR-0112**：触发式选择读作**调用暂存**——提交物化为该轮调用记录，「挂载 + 激活」复合与幂等吸收语义退役。
- **校准 ADR-0118**：Decision 1 种子读作**发现快照**（填充语义不变、载体显式入 recipe）；Decision 4 chip 卸除退役（其止血对象——每轮重组装——随本 ADR 消亡）；Decision 5 三层闭环的「退场」半边改由「过期 + 启用轴」承担；Decision 2/3/6/7 维持（Decision 7 的凝固语义另获缓存论证）。
- **校准 ADR-0111**：Decision 3 门控从激活集改会话内已调用集；卸载级联摘除面随激活态消亡；Decision 4 自纠三态中「挂载未激活」分支退役。
- **校准 ADR-0086**：`RecipeEntry::Skill` 事件变体由调用记录继任——新语义不再产生技能事件，旧信道并存期继续产生与折叠，随旧信道全链退役；身份、`content_hash`、诚实降级、正文点名工具引用纪律不变，出处形状由调用记录承载。
- **CONTEXT.md 校准**：「技能」（挂载 → 发现快照、渐进披露三层重述）、「技能激活」改写为「技能调用」、「技能生命周期事件」退役、「网关」「子智能体」的元工具枚举改名。
- **留实施期**：`invoke_skill` 工具描述与索引引导语措辞、调用记录在轮次窗口装配中的位置（用户调用先于提问 / agent 调用随调用点）、气泡徽章视觉与键盘面、v7 拒开报错文案、发现快照的 recipe 字段形状、i18n 键增删与测试面收缩清单。
