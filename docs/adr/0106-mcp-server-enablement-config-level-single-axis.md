# MCP 服务器启用:配置级单轴开关取代逐会话挂载

## Decision

1. **配置级启用开关。** 外部 MCP 服务器注册表条目新增机器级持久 `enabled` 状态，配置页行内切换，写路径复用既有 upsert（继承唯一 id 与秘密扫描校验，不新增专用 IPC）。启用 = 进入所有会话的有效工具面（经网关发现面可达，ADR-0105）；禁用 = 休眠——不连接、不 spawn 子进程、不取 keychain 秘密、不进目录。

2. **单轴：有效集 = 配置启用。** 逐会话用户勾选轴整体退役：composer bar 的 MCP 挂载入口与冷启动待选链一并移除，逐会话 MCP 状态查询与开关 IPC 同批退役。禁用是绝对权威，无任何越权通道。

3. **技能的 MCP 引用降为声明性元数据。** 引用已启用的服务器是无操作（本已在有效集内）；引用禁用的服务器无效果——技能诚实降级：提示片段照常注入、工具缺席，agent 按能力边界纪律（ADR-0079）诚实拒绝并给出 in-scope 替代。引用不改变启用状态。

4. **默认启用。** 新增（表单保存）、导入（外部配置发现的勾选清单）、存量迁移（serde 默认值）一律默认启用——三个入口均已携带显式用户意图；未来的批量安装入口（如服务市场）届时自定默认，不在此预定。

## Context

现行挂载模型是双轴的：有效集 =（用户逐轮勾选 ∪ 技能声明）∩ 已配置，技能优先于用户勾选。用户勾选住在 composer bar 的 MCP 挂载入口，冷启动经待选链在首个会话落地；技能声明的服务器由轮次装配注入。该模型把 MCP 当作每轮策展关注点，其存在动机是平铺广告下的上下文税——用户必须逐轮挑选让哪些工具进上下文。ADR-0105 的发现面使启用的边际上下文成本归零，「启用即可发现」取代「逐轮策展」；「技能优先」的存在动机（替未勾选的用户自动点亮）也随常驻启用态消失。

## Why

1. **可被绕过的关不是关。** 禁用一个服务器的动机——停止其网络访问、不再 spawn 子进程、不再读取 keychain 秘密——要求开关的绝对性；技能内容是外来文本，不应有重新武装被禁用基础设施的权力。
2. **单轴零例外。** 「为什么这个服务器在被使用」永远只有一个答案；双轴保留优先级规则与每轮按挂载技能集重算的语义分叉。
3. **发现面使默认启用无代价。** 启用不再意味着上下文洪水，只意味着进目录待发现——「默认启用」在平铺时代的真实代价已被 ADR-0105 消除。
4. **每个入口已有显式意图。** 新增的保存、导入的勾选、存量的「曾经配置过」是等价的意图证据；默认禁用只制造「明明加了却找不到」的支持负担。

## Considered options

- **技能声明越权点亮（延续技能优先语义）**：挂载技能可静默复活被禁用服务器，开关承诺失效，外来文本获得重新武装基础设施的权力。**否决**——绝对权威，技能引用降为声明性元数据。
- **默认禁用 / 分裂默认（新增启用、导入禁用待审）**：待审的是服务器行为（探针与工具列表已覆盖）而非存在性；默认禁用让用户对同一意图二次表达。**否决**——一律默认启用。
- **保留瘦身版全局状态 IPC（向配置页镜像「上次连接态」）**：无消费方；诊断已由探针按需覆盖，当轮连接错误经 trace 与 `mcp_list_servers`（ADR-0105）双通道可见。**否决**——逐会话 MCP IPC 全撤。
- **启用开关专用 IPC**：开关即一次字段编辑，专用通道制造第二写路径。**否决**——复用 upsert。
- **注册表拆独立配置存储**：容量不是压力点（百条目为数十 KB 量级）；真实压力（条目归属轴、连接经济学）以加法字段 / 连接池演进即可解决；拆分使严格读 / 导出 / 回滚仪式翻倍。**否决**——留在 app-config，读写不越出注册表边界。
- **per-project 作用域配置（不同项目不同服务器集）**：须在领域模型引入会话之上的项目容器层；单用户桌面、会话即单元的现状无其服务对象。**否决**——作用域扩展另待真实需求。

## Consequences

- **校准 ADR-0076**：聚合来源从「内置 + 用户配置外部 MCP 服务器 + 技能声明的工具」收敛为「内置 + 启用的用户配置外部 MCP 服务器」；命名空间句柄、网关唯一强制点立场不变。ADR-0076 已加反向指针。
- **不触碰 ADR-0092**：composer bar 的 shell 级立场不变，仅移除其上的 MCP 挂载入口。
- **技能自足性的诚实代价**：带服务器引用的技能在服务器禁用时功能不完整，用户须至配置页启用方可完整使用；设置页的「技能引用了未启用服务器」提示为可选后续。
- **IPC 与类型退役（实现期执行）**：逐会话开关与状态 IPC、启用来源双源类型、composer 挂载组件链、冷启动待选链、对应查询键 / i18n / 测试。
- **CONTEXT.md 校准**：「网关」来源表述、「技能」的 MCP 引用半句改为声明性元数据；新增「MCP 服务器」词条（启用语义）。
- **留实现期**：`enabled` 字段的 serde 形状、前端撤除清单与测试迁移。
