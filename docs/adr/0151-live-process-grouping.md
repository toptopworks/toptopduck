# live 过程分组：单行活动线轮换，prose 恒显

> 本 ADR **收窄 ADR-0078 的「live 流式中的调用落地即见」决策**：live 过程面由「调用随落逐行平铺」收窄为「当前调用随落随见、封口段各落一行折叠」——活回合的过程面呈「连接话语（恒显） + 单行活动线（思考态/工具态轮换，话语流出期让位）」；ADR-0078 其余裁决（轨迹持久化、按轮分组、远窗只收摘要、settle 过程面收折叠）**保留**。见 ADR-0078。

## Decision

1. **活动线与脸面轮换**：live 回合的过程面 = 连接话语序列 + **单行活动线**；活动线随阶段轮换脸面——调用运行时 = 类别动词 + 完成计数（spinner 骑头，运行调用由线吸收，不再单独成行）；无调用运行时 = 思考态（「思考中（第 N 步）…」，round-trip 等待状态行的职责并入，时长后缀退役，live 期思考不带计时）；话语流出期活动线让位——封口折叠行与话语 + 光标本身即活动证据。
2. **防闪烁契约**：线头只读 operation_kind 与完成计数，不读流式 summary / args；工具脸随调用即时刻画，动词切换按窗口节流，活动停后保脸一窗口——活动吞进思考态读作死线与快调用逐个换脸读作闪烁，两个失败模式由同一窗口挡下。
3. **纯状态行**：线尚无可展开内容（既无思考落痕也无调用行）时是纯状态行——不可点击、无 hover 态。
4. **封口分段落折叠**：活动线的域与落节分界唯一取**封口**；轮按话语节分段（一轮带话语即开新段，无话语轮归入前段），最后一个话语节之前的所有段各**落为一行折叠**——完成态折叠行（以该段调用总数为计数，可点），按轮序原位落在该段话语节之下，具体文案属实现（现行：「执行完成 · N 次调用」）；展开即段内各轮的思考行（与落定同款：「思考 · 时长」，可展开看原始推理）与平铺调用行（名 + 类别徽章 + 参数摘要，拒绝回答徽章随行），与落定轮同构。封口 = 下一个话语节出现，唯一分界，无任何 prose 特例；两话语节之间再长的纯调用段也只落一行，不逐轮铺开；渐进感来自「每次封口只多一行」，结构给出，不靠动画。
5. **线域与计数**：最后话语节之后的段收在活动线——完成调用进头部计数，思考与调用收在展开面，运行调用由线头吸收；全程无话语的回合整段收在活动线（与旧姿态一致）；活动计数只计线域内的调用，已封口段的调用不再由线报数。
6. **边界与落定**：gate 待答卡不进活动线、恒在回合尾部可见（ADR-0083）；settle 交换后活动线让位于 outcome 体，展开姿态为交换进来的轮级过程折叠播种——用户正在读的过程面在落定后原位保持展开；折叠状态会话内即逝，不跨会话持久化。

## Context

ADR-0078 的 live 姿态是「live 流式中的调用落地即见」：调用随落逐行平铺，与 settle 后整体收折叠形成同一过程面在相邻两阶段的密度断崖，长回合下 live 进程区高度随调用数线性增长。按轮或按话语分节的形态在多轮回合下产生行噪声——同名词行连排或计数行逐节重置，读作闪烁。模型的连接话语是叙事线本身，活动状态是一行轮换的脸：过程信息的「现在」压缩到一行，「历史」按封口落折叠且与落定后的呈现同构——两个阶段的形态差只剩「已封口的折叠在」与「未封口的收在线」。审批卡是用户必须作答的流内卡（ADR-0083），不进活动线。

## Why

1. **「随落随见」的价值核是当前调用可见**（活动证据）；全量过程的价值在审计与回溯，按需展开两全——settle 侧同判（ADR-0078），live 侧收窄是同一逻辑在活回合的延伸。
2. **高度恒界**：过程面外面积 = 话语段 + 一行，不随调用数或轮数线性增长；活动线的脸面轮换是唯一的状态变化，结构性行增减为零（除话语段落本身的增长）。
3. **防闪烁是单行成立的前提**：线头若读流式内容，参数逐字到达期间文案抖动；只读 kind 与计数，不读流式内容；动词切换按窗口节流、工具脸退场带保脸窗口——快调用逐个换脸与逐字文案是同型闪烁，而活动被吞进思考态同样读作死线，两头都由同一窗口挡下。
4. **落节即落定面**：封口段折叠行的展开内容与 settle 后的过程面同构（思考行、调用行平铺），settle 交换不移动用户正在读的面——展开姿态播种落定轮的过程折叠，落点逐层一致；渐进感来自「每次封口只多一行」，结构给出，不靠动画。

## Considered options

- **按轮分组（每轮一组行）**：多轮回合退化为「每轮两行」，计数每轮重置、组行逐轮重挂，读作持续闪烁。**否决**。
- **prose 锚定分节（节组行跟随话语）**：无话语回合（外部运行时）退化为单节后，有话语回合的节组行与薄思考行串仍产生行噪声（同名词行连排）。**否决**（被单行活动线取代；话语保留为恒显叙事线）。
- **回合级单组（全回合一组行 + 独立尾行）**：活动行与等待状态行双行并存，思考呈现与活动呈现割裂。**否决**（被单行轮换吸收）。
- **话语流出期输出态（「输出中」命名流出相位，活动线恒驻）**：与思考态交替翻转读作怪异，封口折叠行已占状态位、话语 + 光标即活动证据，输出态属双显。**否决**（流出期线让位）。
- **按话语存在性揭示（无话语轮收在线 / 话语出现后恒显）**：分界随话语出现与否漂移。**否决**（分界唯一取封口——下一个话语节出现，规则单一）。
- **封口整块落节（思考+调用行原位铺开）/逐轮一行折叠**：前者在多调用的段封口瞬间整块铺开、无渐进感；后者在长纯调用段下退化为折叠行连排。**否决**（按话语节分段聚合，一段一行）。
- **展开面嵌套折叠（轮调用套工具名计数折叠头）**：展开本身已是「看细节」的语境，嵌套折叠多一层点击。**否决**（平铺；思考行与落定同款带时长）。
- **完成行停留动画 / 折叠态泄漏行**：与防闪烁目标冲突，组外面积随活动行数波动。**否决**。

## Consequences

- **校准 ADR-0078**：live-unfolded 姿态由全量平铺收窄为「当前调用随落随见」；「live 流式中的调用落地即见」由本 ADR 承接新口径。
- **校准 ADR-0078/0103 的 live 思考呈现**：live 封口段的思考行与落定同款（「思考 · 时长」，居折叠行展开内）——两个阶段的思考呈现零差异；settle 折叠头保留同款时长标签；rail 等待时长后缀退役（bar 侧回合时钟不受影响）；思考折叠展开态连续性随 live 思考折叠载具退役（settle 折叠态回归纯会话即逝）。
- **settle 正典衔接**：封口落节即落定面（段序原位折叠行、展开平铺调用行、思考行带时长）；settle 侧轮折叠头（按工具名计数）与封口折叠的平铺形态并存——落定后二次收拢是既有长轨姿态（ADR-0078），live 不预演。
- **恒可见面边界**：待作答的审批卡（ADR-0083）不进活动线、恒在回合尾部；被 gate 拒绝的调用行是完成行——计入所在轮，已封口段的随折叠行展开、线域内的进活动计数，回答徽章随行。
- **折叠状态会话内即逝**：活动线展开态跨 settle 交换播种落定过程折叠（seed 模式），不跨会话持久化（会话即逝是既有裁决）。
