# live 过程分组：单行活动线轮换，prose 恒显

> 本 ADR **收窄 ADR-0078 的「live 流式中的调用落地即见」决策**：live 过程面由「调用随落逐行平铺」收窄为「当前调用随落随见、轮完成即定格为落定同构行」——活回合的过程面呈「定格轮的同构行序列 + 单行活动线（思考态/工具态/流出运行态轮换，恒驻走秒）」；ADR-0078 其余裁决（轨迹持久化、按轮分组、远窗只收摘要、settle 过程面收折叠）**保留**。见 ADR-0078。

## Decision

1. **活动线与脸面轮换**：live 回合的过程面 = 连接话语序列 + **单行活动线**；活动线随阶段轮换脸面——调用运行时 = 类别动词 + 完成计数（spinner 骑头，运行调用由线吸收，不再单独成行）；无调用运行时 = 思考态（「思考中（第 N 步）…」，round-trip 等待状态行的职责并入，思考时长后缀退役，live 期思考不报自身时长）；话语流出期 = 运行态（spinner + 「执行中…」）——话语 + 光标即流出自身的活动证据，运行面只认运行中的事实、不命名流出相位；活动线恒驻不退场，线头随面轮换挂回合走秒 figure，turn 全程时钟连续。
2. **防闪烁契约**：线头只读 operation_kind 与完成计数，不读流式 summary / args；工具脸随调用即时刻画，动词切换按窗口节流，活动停后保脸一窗口——活动吞进思考态读作死线与快调用逐个换脸读作闪烁，两个失败模式由同一窗口挡下。
3. **纯状态行**：线尚无可展开内容（既无思考落痕也无调用行）时是纯状态行——不可点击、无 hover 态。
4. **轮完成即定格**：活动线的域与落节分界唯一取**轮完成**；尾轮之前的每一轮定格为落定同构的显式行序列——话语正文（若有，恒显）+ 思考行（与落定同款：「思考 · 时长」，可展开看原始推理）+ 轨迹行（按工具名计数的折叠头，可展开为平铺调用行：名 + 类别徽章 + 参数摘要，拒绝回答徽章随行），按轮序原位落在活动线之上，与落定轮逐项同构。轮完成 = 轮内调用行全部完成且无运行行，即其后继轮已开启；无话语轮与带话语轮同判，话语不承担分界角色——agent 不产话语的长回合逐轮推进，不再无限累积于一线。
5. **线域与计数**：活动线的域唯一取当前运行轮（turn 尾轮）——完成调用进头部计数，思考与调用收在展开面，运行调用由线头吸收；活动计数只计当前轮的调用，先前轮的调用已随其定格行可见；round-trip 等待期线仍驻尾轮，settle 交换是线的唯一退场。
6. **边界与落定**：gate 待答卡不进活动线、恒在回合尾部可见（ADR-0083）；settle 交换后活动线让位于 outcome 体，展开姿态为交换进来的轮级过程折叠播种——用户正在读的过程面在落定后原位保持展开；折叠状态会话内即逝，不跨会话持久化。

## Context

ADR-0078 的 live 姿态是「live 流式中的调用落地即见」：调用随落逐行平铺，与 settle 后整体收折叠形成同一过程面在相邻两阶段的密度断崖，长回合下 live 进程区高度随调用数线性增长。按轮或按话语分节的形态在多轮回合下产生行噪声——同名词行连排或计数行逐节重置，读作闪烁。模型的连接话语是叙事线本身，活动状态是一行轮换的脸：过程信息的「现在」压缩到一行，「历史」按轮定格落折叠且与落定后的呈现同构——两个阶段的形态差只剩「已定格的同构行在」与「当前轮收在线」。分界从话语改判轮完成是对初版话语分界的再校准：话语分界下 agent 不产话语的回合一线无限累积（折叠态长时间只有一行活动线、展开全量平铺，既无推进感也不可读），轮分界让长纯调用回合获得轮粒度的历史推进；当初对「每轮折叠行连排」的顾虑随定格行携带落定同构的信息密度（思考时长、按工具名计数）而消解——静态可扫描的折叠头不是同名词裸行的闪烁。审批卡是用户必须作答的流内卡（ADR-0083），不进活动线。

## Why

1. **「随落随见」的价值核是当前调用可见**（活动证据）；全量过程的价值在审计与回溯，按需展开两全——settle 侧同判（ADR-0078），live 侧收窄是同一逻辑在活回合的延伸。
2. **高度有界**：过程面外面积 = 定格轮的同构行序列 + 一行，随轮数线性（每轮至多两折叠行加其话语）、不随调用数增长；活动线的脸面轮换是唯一的状态变化，结构性行增减只在轮完成时刻发生（每轮一次，方向恒定）。
3. **防闪烁是单行成立的前提**：线头若读流式内容，参数逐字到达期间文案抖动；只读 kind 与计数，不读流式内容；动词切换按窗口节流、工具脸退场带保脸窗口——快调用逐个换脸与逐字文案是同型闪烁，而活动被吞进思考态同样读作死线，两头都由同一窗口挡下。
4. **落节即落定面**：定格轮与 settle 后的过程面逐项同构（思考行、轨迹折叠头、调用行平铺），settle 交换不移动用户正在读的面——交换的唯一变化是活动线让位于 outcome 体与展开姿态播种的落定轮级折叠，落点逐层一致；渐进感来自「每轮完成只多其同构行」，结构给出，不靠动画。

## Considered options

- **按轮分组（每轮一组行）**：多轮回合下组行逐轮重挂，读作持续闪烁。**否决**（裸组行形态——行无摘要头、计数逐节重置；后继的轮完成定格形态成立，因其折叠头携带落定同构的信息密度，静态可扫描，与重挂的裸行组不同形）。
- **prose 锚定分节（节组行跟随话语）**：无话语回合（外部运行时）退化为单节后，有话语回合的节组行与薄思考行串仍产生行噪声（同名词行连排）。**否决**（被单行活动线取代；话语保留为恒显叙事线）。
- **回合级单组（全回合一组行 + 独立尾行）**：活动行与等待状态行双行并存，思考呈现与活动呈现割裂。**否决**（被单行轮换吸收）。
- **话语流出期输出态（「输出中」命名流出相位）**：与思考态交替翻转读作怪异，话语 + 光标即流出证据，命名相位属双显。**否决**（流出期渲染不命名相位的运行态；线恒驻以承载回合恒显钟）。
- **按话语存在性揭示（无话语轮收在线 / 话语出现后恒显）**：分界随话语出现与否漂移，agent 不产话语的回合一线无限累积。**否决**（分界唯一取轮完成，规则单一且与话语无关）。
- **封口整块落节（思考+调用行原位铺开）**：多调用的段封口瞬间整块铺开、无渐进感。**否决**（轮完成定格取代——每轮完成只落其同构行）。
- **展开面嵌套折叠（轮调用套工具名计数折叠头）**：展开本身已是「看细节」的语境，嵌套折叠多一层点击。**否决**（平铺；思考行与落定同款带时长）。
- **完成行停留动画 / 折叠态泄漏行**：与防闪烁目标冲突，组外面积随活动行数波动。**否决**。

## Consequences

- **校准 ADR-0078**：live-unfolded 姿态由全量平铺收窄为「当前调用随落随见」；「live 流式中的调用落地即见」由本 ADR 承接新口径。
- **校准 ADR-0078/0103 的 live 思考呈现**：live 定格轮的思考行与落定同款（「思考 · 时长」，显式一行，展开看原始推理）——两个阶段的思考呈现零差异；settle 折叠头保留同款时长标签；rail 等待时长后缀退役（回合时钟不属退役之列：恒驻活动线头，面轮换与姿势切换间同一 DOM 位连续走秒）；思考折叠展开态连续性随 live 思考折叠载具退役（settle 折叠态回归纯会话即逝）。
- **settle 正典衔接**：定格落节即落定面（轮序原位同构行、思考行带时长、轨迹折叠头按工具名计数）；settle 侧逐轮呈现与 live 定格行同形——settle 交换零重排，落定后二次收拢是既有长轨姿态（ADR-0078），live 不预演。
- **恒可见面边界**：待作答的审批卡（ADR-0083）不进活动线、恒在回合尾部；被 gate 拒绝的调用行是完成行——计入所在轮，定格轮的随其轨迹行展开、当前轮的进活动计数，回答徽章随行。
- **折叠状态会话内即逝**：活动线展开态跨 settle 交换播种落定过程折叠（seed 模式），不跨会话持久化（会话即逝是既有裁决）。
