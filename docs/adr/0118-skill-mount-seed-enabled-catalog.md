# 技能挂载自动化：种子扩容为启用全集与索引注入钳制

## Decision

1. **挂载种子扩容为启用全集。** 新会话的挂载集种子从「内置技能（配套 CLI 注册项检测到且启用）」泛化为「注册表 ∩ 技能启用轴」全集；内置技能为双轴合取（技能启用轴 ∧ 配套 CLI 注册项启用轴——CLI 未检测到时其配套技能本就不进种子，既有语义维持）。挂载语义逐字不变（挂载 = 可发现集 = 唯一信任闸门，ADR-0110 Decision 1），变化的只是填充方式：从「用户逐会话精选 + builtin 特例」到「启用全集自动种子」。种子不落生命周期事件（现状继承）。技能使用的信任表达面从会话级挂载操作迁移到机器级启用轴。

2. **新增技能启用轴。** 机器级单轴、住 app-config 名字集合（与 agent 定义同型）、默认启用——新建 / 导入即启用，开箱零操作。禁用 = 不进种子（不可发现）、文件保留、设置面灰显可见——「禁用即休眠」语义与 MCP 服务器一致。至此四个注册面（MCP 服务器 / CLI 注册项 / agent 定义 / 技能）同构收口：启用即进会话有效面、禁用即隐身。

3. **元数据索引注入钳制。** 索引行的 `description` 注入时钳 360 字符、截断以 `…` 尾标；注册表校验上限 1024（Agent Skills 规范）不动、导入兼容不受影响，设置面等本地消费继续看全文。钳制是护栏不是常态——发现质量责任仍在 description 策展（ADR-0110 Decision 7 继承）。中文满额行约 180–240 token（中文字符 token 密度约为英文 3–4 倍），是钳制值的产品语境。

4. **会话内退场 = 激活 chip 卸除。** 激活技能的预激活 chip 加移除 affordance，移除即卸载（级联失活、摘预激活意图——ADR-0110 Decision 4 语义逐项复用）。卸载语义随之弱化为**会话级否决**：新会话重新种子、被卸技能回归可发现；永久移除走启用轴禁用。两层各诚其实——会话级退场与机器级禁用。

5. **激活行为约束零新增。** 索引引导语维持现状（任务匹配即激活）；激活免审批维持（ADR-0110 Decision 3——启用轴是比会话挂载更持久的信任表达，全直通论证链不变）。约束靠三层闭环：入口（description 策展）→ 过程（引导语）→ 退场（chip 卸除）；收紧引导语会把误激活税换成漏激活税——后者恰是本 ADR 要消灭的使用负担的镜像。

6. **挂载 UI 退役、picker 保留。** 挂载 popover（触发 chip + 面板）与冷启动 pending 挂载流程退役；`/`、`$` 输入框触发式选择保留为显式激活通道，其「挂载 + 激活」复合在种子全集后退化为事实幂等（缺挂则补挂、幂等吸收）；设置面升级为唯一管理面（CRUD + 启停）。

7. **存量会话能力面凝固。** 种子 = 会话创建时点的启用快照；存量会话与 resume 不重种子（timeline fold 权威不变）——中途新启用的技能经 picker 补挂或新会话可达。

校准：v1 不设种子数量护栏（启用全集直接种子）；导入大技能库的真实场景出现时再评估「超限回落精选」。

## Context

ADR-0110 把挂载收敛为元数据索引（每行成本到 `description` 量级）、激活收敛为免审批双 actor 元工具、外部运行时与内置逐位平权——发现面的全部构件已就位，唯独入口仍是「用户逐会话精选挂载」。用户须知道技能存在、判断任务适用、每会话重复操作，使用门槛与技能数量成正比；而任务-技能的匹配判断本是模型所长，目录常驻即可自主路由。builtin 自动挂载（ADR-0110 Decision 7）已验证自动种子的形态，缺的是从特例到全集的泛化与一根尚不存在的机器级启用轴。全量种子的边际成本 = 索引行数 × 钳制后 description——有界且可控。

## Why

1. **用户不应是路由器**：目录常驻 + 模型自主激活后，用户操作坍缩为设置面一个开关；「记住技能清单、判断适用」的认知负担整体消失。
2. **挂载语义零破坏**：本 ADR 是 builtin 自动挂载的泛化，不是「全库可发现」（ADR-0110 Why 2 否决项）——挂载集、生命周期事件、卸载级联全部原样，仅填充自动化。
3. **四面同构收口**：技能补齐启用轴后与 MCP 服务器、CLI 注册项、agent 定义同型，注册面治理模型唯一。
4. **成本有界**：注入钳制封顶单行；策展责任（短而准的 description）是发现质量的既定答案；正文税仍由激活子集承担（ADR-0110 成果不回退）。
5. **控制权分层诚实**：会话级否决（chip 卸除，agent 误激活的即时止血）与机器级禁用（启用轴，跨会话）各归其位，两层都不缺位。

## Considered options

- **全库可发现、挂载退役**（ADR-0110 Why 2 否决项重审）：摧毁生命周期词汇、卸载级联失效、无启用轴时控制面无落点。**否决**——种子扩容保留挂载语义（Decision 1）。
- **注册表 description 上限降至 360**：拒绝规范合法的长描述导入、强牵连无 token 税的本地消费面。**否决**——注入级钳制（Decision 3）。
- **激活确认门或硬配额**：确认门已被 ADR-0110 Why 5 否决（启用轴仍是持久信任表达，论证不变）；配额数字无产品依据且误伤合法多技能会话。**否决**——三层闭环零新增（Decision 5）。
- **会话内无退场（止血仅设置面禁用）**：agent 误激活的正文持续注入税止血距离过远。**否决**——chip 卸除（Decision 4）。
- **种子数量护栏（超限回落精选模式）**：当前启用数为个位量级，无场景支撑。**否决**——YAGNI，记入校准留尾。

## Consequences

- **CONTEXT.md 校准**：「技能」条目（启用轴 + 种子填充）、「技能激活」条目（Avoid 行启用语义收窄为会话态对照）、「内置 CLI 注册项」条目（配套技能种子条件改双轴合取）。
- **校准 ADR-0110**：Why 2「用户对会话能力面的控制权」落点从会话挂载轴读作机器级启用轴；Decision 7 builtin 自动挂载读作 Decision 1 全集种子的特例；留实施期「挂载数量大时的索引上限策略」由本 ADR Decision 3 钳制收编。
- **校准 ADR-0112**：触发式选择的「挂载 + 激活」复合读作事实幂等（种子全集后挂载半边几乎总已就位）。
- **校准 ADR-0092**：冷启动 pending 挂载流程随挂载 UI 退役。
- **继承 ADR-0110 全部机制决策**：渐进披露三层、激活免审批、卸载唯一出口、出处记激活集、format_version v6——本 ADR 零改动。
- **留实施期**：启用轴的 app-config 节形状与迁移（存量视为全启用）、设置面启停控件形态、chip 移除 affordance 的视觉与键盘路径、索引钳制的渲染函数落点、i18n 键增删与测试面收缩清单。
