# 运行时段:resume 段延续与姿势随段回填

## Decision

1. **resume = 段延续**：恢复会话**最后生效段头的运行时**与该运行时下的姿势对（model / thought_level）。两者由构造保证同源——会话内换运行时即按新运行时回填姿势（Decision 3），`last_runtime` 在轮末（轮次归属快照）与 set 命令的即时持久化点两处盖章、后者与所持久化的姿势对同批落盘，持久化的姿势对永远属于持久化的运行时，不存在跨命名空间悬空，无需归属字段或条件恢复。`last_runtime` 入 recipe 头，与姿势对、`cached_discovered` 同批持久化（随既有 persist-now 机制）。

2. **执行面 / 安全面分类**：执行面选择（运行时 + 模型姿势）是**会话延续状态**，跨 resume 恢复；安全面姿态（审批模式、MCP 启用）维持 resume 即重置的装配姿态。运行时选择不再与审批模式、MCP 启用同批于 resume 重置。

3. **新时段起步统一回填**：新会话与会话内换运行时开启新时段，起步时模型姿势槽按目标适配器回填——外部运行时 := 该适配器的「上次模型姿势」回填条目（可能为空 = 未选择态「默认（推荐）」），内置运行时 := 空（内置不消费姿势）。时段内显式选择覆盖当前槽位并即时更新回填条目——单一写入点不变（ADR-0100）。

4. **resume 降级语义**：持久化的 `last_runtime` 指向的适配器 resume 时未 detected，该次 resume 降级为内置起步、持久值不销毁（镜像 ADR-0098 Decision 3 的降级语义，重探测后下次 resume 复效）；姿势对随之休眠，用户切回该适配器时按 Decision 3 回填。

## Context

会话内换运行时已落地为必要的可选操作（轮次边界生效、thread 可混跑），留下两处断裂：其一，会话内换运行时不清姿势——旧适配器命名空间的 model id 原样悬空，注入侧无命名空间校验，外域 id 注入新 CLI 以轮次失败收场；其二，resume 按 ADR-0098 Decision 2 把运行时回落默认运行时（与审批、MCP 启用同批重置），却按 ADR-0095 Decision 6 恢复会话姿势对——两者适配器不一致时姿势悬空，且会话内已表达的运行时选择在 resume 处断裂，重开落到机器级偏好上。冷启动 bar 换运行时已重置 pending 姿势并回落目标适配器回填，与会话内行为不对称。

## Why

1. **resume 的语义是继续这个会话**：执行面状态（用什么引擎、什么参数）是会话内已表达的状态，延续无需重新授权；新会话才需要显式偏好（默认运行时）回填起步。
2. **段延续让姿势与运行时由构造同源**：条件恢复、归属字段、双源调和全部不需要——该类错配被消灭而非容忍。
3. **执行面 / 安全面分类有独立论证**：审批模式与 MCP 启用的 resume 重置是安全姿态（重新显式确认）；运行时与模型姿势是执行参数，无重确认诉求——原先同批重置是家族惯例沿袭，并非针对运行时轴的独立论证。
4. **与既有否决不冲突**：ADR-0100 否决的是把「上次使用的运行时」延续到**所有新会话**（未表达意图的静默延续）；resume 延续的是本会话内已表达的状态，作用域不同。

## Considered options

- **会话内切换保留悬空姿势（维持现状）**：注入侧无校验，外域 model id 注入新 CLI 以轮次失败收场。**否决**——注入侧校验缺失导致轮次失败。
- **切换即清空**：同一适配器来回切换丢选择。**否决**——按目标适配器回填保留自动复得。
- **resume 回落默认运行时 + 姿势一律回填（会话姿势对退役）**：会话自身的执行选择在 resume 处让位于机器级记录；「期间其他会话动过同适配器」窗口下回填与会话最后选择分歧。**否决**——会话连续性断裂。
- **resume 回落默认运行时 + 姿势对附带归属适配器条件恢复**：读时分支解决错配，但 resume 落到非会话运行时本身即连续性断裂，且持久化形状多一字段。**否决**——段延续。
- **会话内 per-adapter 姿势记忆（map）**：单槽 + 段延续已覆盖 resume 恢复与切回复得（切回时回填条目按单一写入点与会话最后选择同步），全量记忆无对应需求支撑。**否决**。

## Consequences

- 校准 ADR-0098 Decision 2：resume 半边反转——resume 恢复会话最后生效段头的运行时，不再回落默认运行时；新会话半边与「会话内切换不回写默认」不变。默认运行时的作用域收窄为新会话起步（含冷启动 pending 回填）。
- 扩展 ADR-0095 Decision 6：resume 恢复的持久化字段由三项扩为四项（+ `last_runtime`）；「set means persisted」载体不变。
- 延伸 ADR-0100 Decision 1：回填作用域从「新会话起步」扩为「新会话与会话内换运行时起步」；resume 不在其列。
- recipe 头新增 `last_runtime`；存量 .duck 缺字段按 serde default 回落旧语义（默认运行时解析），新写入起一律携带；format_version bump 与否实施期定。
- 会话内换运行时的写路径补回填接线；resume 路径补 `last_runtime` 与姿势对恢复。set 命令（模型 / 思考强度）的即时持久化点补 `last_runtime` 盖章（Decision 1 的段头语义）。运行时槽与姿势对槽共用单一互斥槽：切换的合写与 set / ask 的合读互斥，盖章头与回填条目出自同一次原子读，错位组合在构造上不可达。
- CONTEXT.md：「默认运行时」「运行时段」「上次模型姿势」词条校准。
